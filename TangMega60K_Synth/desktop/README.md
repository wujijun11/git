# TANG / NEON STUDIO 1.0.4

为 Tang Mega 60K 钢琴主工程制作的 Windows 桌面控制软件，参考用户提供的
8 秒演示视频中的电脑键盘、虚拟琴键、音色和参数控制，重新设计为深色霓虹工作台。

本版将待执行命令限制为128条。“全部停止”会取消尚未发送的旧操作，在当前
ACK/数据事务完成后优先停止；断开时按已经收到ACK的音符记录释放远程音符，
不再继续发送积压演奏。同步回调重入不会再造成并发写入或丢失等待结果。
此前修复的整批旧音符释放顺序仍保留。通信协议和接线保持兼容；回归记录位于
`../verification/second-code-review-20261023/`。

1.0.4 增加可选的 C3 只读诊断：原生蓝牙通道在发送首个协议命令前保存基线，
断开前再读取一次现有 DIAG004 特征，每次最多等待0.75秒。握手失败时仍立即
停止协议会话，再补充显示 C3 的蓝牙收帧、UART提交、UART返回和通知计数。
原 ACK 超时信息会保留，协议超时、帧格式与接线没有改变。

只识别40字节 TBv1 和16字节旧版错误计数。缺少基线时只显示累计值，
不把它归因于本次连接；缺少特征、读失败或未知格式不阻断原连接/断开流程。
“C3报告已提交UART”不是实际引脚传输或 FPGA ACK 的证明。诊断结果也会写入
导出的会话日志。串口与演示模式不读取该特征，迟到的旧连接结果不会覆盖新连接。
定向软件验证位于 `../verification/ble-connection-fix-20261023/`。

## 启动

解压完整便携包，双击 `TangNeonStudio/TangNeonStudio.exe`。请保留同目录的
`_internal` 文件夹；运行不需要另外安装 Python。本机已安装的 Microsoft Edge
WebView2 Runtime 是窗口渲染依赖，打包自检会检查它。

首次打开可点右上角 **连接设备 → 离线演示 → 进入演示模式**。再开启
**电脑试听** 即可用鼠标或电脑键盘演奏。电脑试听使用本机合成音源，与 FPGA
实际音色不同；演示状态始终标为“离线演示”，不代表连接了硬件。

## 连接当前项目

1. FPGA 运行带 V1 远程协议的完整主工程，ESP32-C3 运行现有 BLE 桥接固件。
2. 按已核对的 Dock 接线保持 C3 GPIO7 TX → FPGA J13-7 / A14 RX、C3 GPIO6 RX
   ← FPGA J13-8 / A13 TX，GND 共地，并给两板供电。
3. 关闭手机中占用此设备的 App。电脑软件点 **连接设备 → 蓝牙 BLE → 扫描**，
   选择 **Tang-Synth-C3**。
4. 通知订阅和 FPGA 应答、映射、配置同步都通过后，才显示 **FPGA 已连接**。
   仅蓝牙链路成功但 FPGA 不回应时，不会冒充可用状态。

FPGA DEBUG USB 用于下载和 GAO；当前 C3 USB 串口只输出日志。**USB-UART** 选项
需要另接 3.3V USB-UART 到 FPGA 的 UART RX/TX/GND，115200 / 8N1。不要让
C3 TX 与 USB-UART TX 同时驱动同一个 FPGA RX。软件不自动更改 C3 固件。

## 演奏与功能

- 25 个虚拟琴键，默认 C4–C6 / MIDI60–84，支持鼠标、多指针和电脑键盘。
- 低八度 `Z S X D C V G B H N J M`；高八度 `Q 2 W 3 E R 5 T 6 Y 7 U I`。
  键面标有快捷键；输入框有焦点时不会触发演奏。
- 正弦、风琴、参数钢琴、FM 电钢琴；主音量、力度、弯音、颤音和四种空间效果。
- 内置曲谱，以及本地“小星星”“霓虹漫游”示例。支持项目原有 JSON 曲谱导入、
  顺序上传与最终提交，最多256条事件；实际定时与发音由 FPGA 完成。
- FPGA 音符事件录音、最多1024条回读、JSON 导出。录音不是 WAV/PCM。
  当前 FPGA 本地录音回放只接受实体琴键来源25–49；电脑来源63可导出保存。
- 25 键自定义 MIDI 映射；灯光指引；实时声部数、欠载计数、录音/播放状态。
- `Esc` 或“全部停止”发送全局停止。窗口失焦仅释放电脑持有的音符。

演奏视界默认是**命令事件动画**，不是 FPGA 波形。点击“音频输入”并由用户允许
麦克风访问后，可显示电脑音频输入频谱；声音仅在本机分析。原协议没有实体触摸位、
逐键音符推流或 PCM 回传，因此不会把动画冒称为板上频谱，也不自动高亮未知的实体触键。

## 曲谱 JSON 示例

```json
{
  "version": 1,
  "title": "两端音高",
  "rows": [
    {"deltaMs": 0, "key": 0, "velocity": 100, "on": 1},
    {"deltaMs": 500, "key": 0, "velocity": 0, "on": 0},
    {"deltaMs": 100, "key": 24, "velocity": 100, "on": 1},
    {"deltaMs": 500, "key": 24, "velocity": 0, "on": 0}
  ]
}
```

`deltaMs` 为相对上一条事件的毫秒数。key0–24、velocity0–127、on0/1，均为整数。
文件读取限制4MiB，所有数据先验证后发送。

## 开发与构建

`web/protocol.js` 逐字复用 `../mobile/web/protocol.js`。`web/controller.js` 处理完整
握手、同序号重试、ACK与数据两包读取、1秒心跳、40ms表情合并和会话代际隔离。
`native_host.py` 只处理蓝牙或串口字节传输以及本机文件对话框。

使用 Python3.12 x64 运行 `build.ps1`，依赖固定在 `requirements.txt`，安装到项目
`tmp/desktop-python`，不改变全局 Python 环境。产物为 `dist/TangNeonStudio`。

验证证据在 `../verification/desktop-app-20261021/`：控制器协议回归、原生传输测试、
实际 Chromium 的界面演奏/曲谱/录音/取消测试、截图、打包自检和哈希清单。
自动协议模拟和库导入通过，不等于实机蓝牙、DAC、功放和琴键声音已经验收。
