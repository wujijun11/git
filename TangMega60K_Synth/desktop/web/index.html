HARDWARE LINK / 连接说明

连接你的声音引擎

  1. 01FPGA 运行完整主工程，并给 ESP32-C3 供电。
  2. 02C3 GPIO7 → FPGA J13-7 / A14；GPIO6 ← J13-8 / A13；GND 共地。以已核对的 Dock 接线为准。
  3. 03选择蓝牙设备 Tang-Synth-C3，等待 FPGA 握手通过。

DEBUG USB 用于下载和 GAO。C3 当前 USB 仅输出日志。串口模式需要外接 3.3V USB-UART 到 FPGA UART，115200 / 8N1，并避免 C3 TX 与串口 TX 同时驱动。
