# 31005接口映射核对

核对日期：2026-10-17。本文是原理图和当前CST之间的离线网名核对，不是现场导通、电压或功能测试记录。

## 核对方法与适用范围

用户此前照片显示底板编号为31005，工程器件为Tang Mega 60K。31005本地原理图的标题是138K Dock，因此不能将其中的138K球位直接套用给60K。本次依次核对：

1. 当前 `full/contest_full.cst` 的60K封装球位。
2. 60K核心30354原理图第1页中，该球位到C2399连接器的实际脚号；随后用30353原理图第1页复核同12路。
3. 31005底板原理图第7页中，与C2399配对的J1同号触点所连接的底板网名。
4. 31005底板原理图第19页中，该底板网名到J13的脚号。

以下结论适用于这组原理图对应的硬件连接。装配前仍须在实物确认底板编号、J13/J9丝印、pin1方向、排针安装和供电；本文没有证明现场硬件与原理图完全一致。不得按照片左右关系猜孔号。

30353与30354两份本地60K核心原理图第1页的这12路球位到C2399触点映射相同。这里只比较本表所需连接，不据此宣称两个核心版本的全部电路一致。

## 供电与地

31005原理图第19页明确：

| 接口 | 网名／作用 | 装配说明 |
| --- | --- | --- |
| J13-11 | `5V_Peripheral` | 是5V，不能接MPR的3.3V脚。外接LED独立供电方案不使用此脚承担灯板电流。 |
| J13-12 | GND | 可作为外设公共地，再经可靠分线连接需要共地的设备。 |
| PMOD0 J9-1、J9-2 | `+3V3` | 原理图上的3.3V取电位置，可经可靠分线供给三块MPR。 |
| PMOD0 J9-3、J9-4 | GND | PMOD0地，可选作MPR地线连接。 |
| PMOD1 J8-1、J8-2 | `+3V3` | 同样是3.3V，但既有DAC使用J8，优先保留已验证的DAC接线。 |

**J13没有默认直接引出的3.3V电源脚。** J13-29为`SDRAM0_EXIO0`，默认经R68连接`SDRAM0_DM0`；接3.3V的R69在原图打叉不装。J13-30为`SDRAM0_EXIO1`，默认经R70连接`SDRAM0_DM1`；接地的R71在原图打叉不装。因此不能把J13-29/30当成3.3V/GND使用。

J9上的一个触点不能硬塞多根杜邦线。需要给三块MPR分电时，使用面包板电源排、可靠分线端子或焊接分线，并先断电操作。J13与SDRAM0共享接口，不可同时装SDRAM扩展模块。
