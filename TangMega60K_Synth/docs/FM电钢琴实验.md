# 两算子 FM 电钢琴：可选实验音色

本方案按照“声音合成方案比较”中的建议制作：64 份独立声部状态，
一条共享计算流水线、两算子 FM、力度主要管音量并适度改变调制指数。
它是 FPGA 实时电钢琴风格音色，不能保证复刻传统钢琴；原钢琴参数音色
仍保留，供听感比较。

## 演奏接口

原 `audio_system_v2` 的 `FM_ENABLE` 参数默认是 0，现有行为不变。
示例顶层 `audio_system_v2_fm` 固定打开 FM 和现有延迟，端口仍是
原 V2 `event_*`、`expr_*` 与 I2S，未修改队长接口、PLL、引脚或 SDC。

开启 FM 后，音色编号为：0 正弦、1 风琴、2 原参数钢琴、3 FM 电钢琴。
3 原先只是风琴的别名；选择 1 仍可演奏原风琴。
由队长的事件分配器把传感器值映射到 `event_velocity`；
`expr_gain/bend/vibrato` 沿用原来逐帧快照路径。
本模块没有擅自新增“压力”或“IMU”公共端口。

## 每个采样怎么计算

每个声部在 `phase_ram` 保存独立的调制器和载波 32 位相位。
读取该声部状态后，按顺序查同一 1024×16 正弦 ROM 两次：

```text
modulator_phase -> sin -> 乘以调制指数 -> 加到 carrier_phase
    -> sin -> ADSR -> 力度 -> 声像/混音 -> 延迟/直通 -> I2S
```

载波频率为实时音高；调制器频率为载波的 3 倍。
调制器从 1/4 周相位起步，使增强谐波时基频不容易相消。
调制指数以弧度解释：力度 40 约为 0.73 rad，力度 127 约为 1.23 rad；
按住约 0.7 秒后平滑退向约 0.25 rad。ROM 接口使用“整周”相位，
因此 ROM 中的指数常量已经预先除以 2π；RTL 不做实时除法。
力度控制指数的范围有限，
避免轻重按变成两种完全无关的音色。
独立包络约为 2 ms 起音、600 ms 衰减到 18.75% 保持、100 ms 松键；
重复触发先有约 2 ms 门控下降，再重启相位和音头。
这些是硬件定点加法、移位、乘法和查表，没有实时软件音源。

FM 算子只实例化一份，轮流处理 64 音；每个音保留不同的相位和音高。
包括现有声音模式与延迟的综合资源不能按“64×一套算子”估算。
原参数钢琴的两条流水线仍作为另一种音色存在，不能假称同时启用
两种声音时没有资源代价。

## 复现

在工程根目录运行：

```powershell
./scripts/test-fm-piano.ps1
python scripts/export-fm-piano.py --input sim/fm_results --previous '<旧钢琴的 raw/03_piano_A4.wav>' --reference '<获许可的 A4v12.wav>'
& 'C:/Gowin/Gowin_V1.9.12_x64/IDE/bin/gw_sh.exe' scripts/synth-audio-fm.tcl
```

首条用隔离目录运行 ModelSim 的 4/64 声部测试、FM 试听、64 音 I2S。
导出的 `raw/` 是仿真原始 24 位 PCM；`listen/` 为明确记录增益的
同窗 RMS 对比，顺序是原钢琴、FM 电钢琴、较强力度的真实参考单音。
原录音只用于离线测量及标注的参考试听，不进入 HDL。

来源：Salamander Grand Piano v3 / Alexander Holm / CC BY 3.0，
固定来源和完整署名在 `assets/audio/README.md`。

## 25 键逐音试听（暂定 C4–C6）

在实际键盘音域尚未定案时，暂按 MIDI 60..84（C4..C6，含两端）验证。
没有改动上述 3:1 FM 运算或 A4 参数；同一音色按各音符的 FTW 实时变调，
不是给每个键存一段录音。独立测试台通过原 V2 `event_*` 与分配器逐键发送
音色 3 的 note-on/off，检查每个音符的释放回收、输出反压和 24 位削波。

```powershell
./scripts/test-fm-keyboard.ps1 -OutputDir ../../../outputs/FM_KeyboardC4C6_20260923
python scripts/export-fm-keyboard.py --input ../../../outputs/FM_KeyboardC4C6_20260923
```

测试台为快速逐键试听采用 `VOICE_COUNT=4`，每次只按一个音；不能将这项
验证称作 25 或 64 音同时发声。64 声部并发另由 `test-fm-piano.ps1` 验证。
导出程序生成 25 个 `raw/` 原始 PCM WAV、25 个统一增益的 `listen/` WAV、
一段 C4→C6 连续音阶和逐音 `analysis.json`。试听增益对所有音符相同，
保留音符间相对音量；它仅用于电脑播放，不写回 RTL。

2026-09-23 的 ModelSim 结果：25 个目标基频全部通过 FFT 检查；
脚本估计最大误差 0.0026 音分、未碰到 24 位削波值，25 次松键均已回收。
这是仿真数字样本的读数，不是板级时钟/DAC 的测量精度。
新测试生成的 A4 与此前 FM A4 试听对齐后，前 7680 帧立体声 PCM 逐样本相同。
正式键盘若改用其他音域，需要重新验证，尤其 MIDI 100 以上的 3:1 FM
高频边带可能混叠；不能将本次 C4–C6 验证推广到全部 128 个 MIDI 音符。

## 边界

本音色首先追求电钢琴式的可控音头，并非对原录音的逐样本拟合。
两算子 FM 的谐波受到调制比和指数约束，无法同时复制真实琴弦的
击弦噪声、多弦拍频和响板共鸣。声音是否更合你的喜好请以试听为准。
资源数字和测试结果以本次生成的 ModelSim/Gowin 报告为准。
布线时序、DAC 实测、现场可闻频谱及总演奏延迟均待上板验证。
