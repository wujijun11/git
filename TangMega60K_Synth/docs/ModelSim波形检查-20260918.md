## 当前波形怎么看

Wave已缩放到2000～2065 us。在波形区单击约2017 us的位置，选中该时间点的光标后能够看到（数值列若仍显示测试结束值，请先单击波形区）：

- `active_count=64`：该时段64个声部在工作。
- `sample_left/right`：实时生成并混合的有符号音频样本。
- `sample_valid/ready`：音源和I2S FIFO的握手；ready拉低期间valid和样本保持是正常反压。
- `bclk/ws/data_out`：串行位时钟、左右声道选择和音频数据。
- `underruns=1`：启动记录保持不再增加。

光标处的`test_passed=0`正常，因为光标停在2 ms附近；只有运行到测试末尾约226.3 ms时才置1。同样，最终`active_count=0`表示测试已经松开所有音符，并非64声部没有工作。

## 重新运行

在ModelSim的Transcript输入以下两行，先切换到工程根目录：

```tcl
cd {C:/Users/asus/Desktop/Git/TangMega60K_Synth}
do sim/waves_audio_v2.do
```

2026-09-19更新：脚本完成后自动保存独立WLF、波形布局和结果摘要，保存在每次新建的 `sim/audio_results/gui_时间戳_编号/` 目录。无需另行保存；如调整了布局，需要刷新同一次结果，可执行：

```tcl
do sim/save_audio_wave_check.do
```

显示 `GUI AUDIO WAVE CHECK PASSED` 和 `AUDIO GUI VERIFIED AND WAVEFORM SAVED` 即为成功。停在 `$finish` 是正常结束，不要继续 `run -all`，否则会继续到测试超时分支。重新测试直接执行 `do sim/waves_audio_v2.do`；脚本会卸载旧设计并重新编译。已有仿真时不要先执行 `cd`，ModelSim不允许在设计已加载时切换目录。

入口先加载完整Tcl过程再启动仿真，避免长时间运行期间逐行读取脚本导致的错位。使用独立编译库及绝对日志路径，避免旧缓存或历史错误混入本次结果。运行期间仍应等测试完成后再编辑脚本。

查看不同时间尺度：

```tcl
wave zoom range 0us 2000us
wave zoom range 2000us 2065us
wave zoom full
```

第一条看声部装载，第二条看I2S细节，第三条看整个发声与释放过程。
