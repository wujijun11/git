# PT8211-S 板载音频格式适配

**历史记录，不再适用于当前工程：已按用户要求移除PT8211模式、参数和专用测试脚本。以下命令与模式选择仅用于追溯当时的适配，不应在当前版本执行。当前统一为24位标准I2S，GUI运行`tb_audio_i2s`。参见[标准I2S恢复记录](恢复24位标准I2S-20260919.md)。**

2026-09-19。适用依据：已核对的NEO Dock Rev 1.4原理图，音频DAC为PT8211-S。完成范围为数字发送格式适配，不等于已完成物理引脚、音频时钟或上板验收。

## 默认行为

`AudioEngine_V2.gprj`的`audio_system_v2`及`audio_system_v2_delay`现在默认`PT8211_MODE=1`。64声部DDS、ADSR、混音和效果仍在FPGA内部运算，内部PCM仍为24位。

| 参数 | 板载PT8211模式 | 保留的标准I2S模式 |
|---|---|---|
| 选择 | `PT8211_MODE=1` | `PT8211_MODE=0` |
| 每声道数据 | 有符号16位，取PCM `[23:8]` | 有符号24位 |
| 每声道槽长 | 16 BCLK | 32 BCLK |
| 左/右WS电平 | 左1、右0 | 左0、右1 |
| MSB位置 | WS切换后的第一个上升沿 | WS切换后的第二个上升沿 |
| 数据采样 | BCLK上升沿 | BCLK上升沿 |
| 数据及WS更新 | BCLK下降沿 | BCLK下降沿 |
| 系统时钟要求 | 49.152 MHz | 49.152 MHz |
| 默认实际BCLK半周期分频 | 16 | 8 |
| BCLK | 1.536 MHz | 3.072 MHz |
| 输出采样率 | 48 kHz | 48 kHz |

共享参数`BCLK_HALF_DIV=8`表示原I2S基准分频，PT8211模式内部将它乘2，以保持每帧1024个系统周期，避免改变DDS音高和64声部的计算预算。仿真时钟的1 ps舍入会造成轻微周期差异，与此前测试相同。

24转16位采用丢弃低8位的有符号截断，不把低16位直接送出，不改变满幅范围。正满幅`7fffff`变`7fff`，负满幅`800000`变`8000`，`ffffff`变`ffff`。会损失低8位分辨率，本次没有增加舍入、抖动或降噪算法。

## 对接和使用

演奏事件、三维表情及队员音源的cmd/done/sample接口不变。只增加编译期参数，不需要队员B重写事件接口。

完整音频工程默认即为板载格式。独立的`captain_system_top_v2`及`i2s_tx`仍默认标准I2S，以兼容原工程；如果直接实例化这两个模块接板载DAC，必须显式设置`.PT8211_MODE(1)`。

为兼容旧顶层，物理信号端口暂保留`i2s_bclk / i2s_lrclk / i2s_data`命名，板载模式下分别对应PT8211的BCK / WS / DIN，协议实际为LSBJ。恢复外接标准I2S DAC时，在完整音频顶层设置`.PT8211_MODE(0)`即可。

GOWIN打开`AudioEngine_V2.gprj`，干声顶层选`audio_system_v2`，延迟顶层选`audio_system_v2_delay`。这些仍是内部接口集成顶层，不能直接作为已经约束的板级顶层烧录。

ModelSim从工程根目录执行：

```tcl
do sim/waves_audio_v2.do
```

现在该入口运行`tb_audio_pt8211`并显示板载格式波形。每个WS半周期应恰好有16个BCLK上升沿。原`tb_audio_i2s`显式选择模式0，继续检查标准I2S格式。

批量测试：

```powershell
./scripts/test-pt8211.ps1 -ModelSimBin 'D:/msim/modelsim_ase/win32aloem'
```

该脚本创建独立源码副本，运行PT8211接口单元测试、64声部加延迟的PT8211串行联调、原64声部I2S回归，并保存PT8211波形。完整`test-audio.ps1`和控制回归`test-iverilog.ps1`也已纳入新增测试。

## 验证范围

`tb_pt8211_tx`的接收模型仅观察BCLK/WS/DIN，不引用发送器移位寄存器。检查有符号端点、左右不同数据、随机数据、低8位丢弃、16位槽宽、采样率、下降沿更新、FIFO满载反压、同时读写、空边界直通、欠载静音和播放中复位；基准DIV=8及边界DIV=1分别运行。

`tb_audio_pt8211`使用默认音频顶层配置，实际启动64个不同音符，开启延迟效果、施加三维表情、松键并等待尾音释放，逐帧比较16位接收值与已接受的24位PCM高16位。

接口测试已分别通过Icarus与ModelSim：DIV=1和DIV=8各解码60帧，包含47个非零输入样本对，均覆盖满FIFO同时读写。原六组Icarus控制/I2S回归也通过。完整音源最终验证结果见本文件末尾。
