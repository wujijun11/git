# 16声部持续发声测试（2026-10-08）

## 操作

保持既有 Tang Mega 60K NEO → PCM5102A → PAM8403 → 两只无源喇叭的接线和供电。功放音量从低档开始。

| 用户键 | 功能 |
| --- | --- |
| KEY0，AA13 | 按一下启动16个正弦音，松手后继续保持 |
| KEY1，AB13 | 停止全部16个音；保留约100ms释放尾音 |
| KEY2，Y12 | 复位静音，清空声部 |

PWR 是电源键。KEY0 不必一直按住，运行中重复按下不会叠加另一组音。16个音同时混合发声，听起来是复合声音，不是依次播放16个音。仅凭听感不能定量证明16声部；实物频谱尚未测量。

## 实现与工程

- 工程：`board16/BoardAudio16_48kI2S.gprj`。
- 顶层：`rtl/board/board_audio_16_48k_i2s_top.v`。
- 发生器：`rtl/diagnostics/poly16_event_source.v`，经原始事件接口驱动既有64声部分配器和音频引擎。
- 固定 MIDI 60–75、正弦音色0、力度100、中性表情、关闭音频延迟效果。一次发送16条 note-on 后保持，KEY1发送配对 note-off。
- 全部为可综合 FPGA HDL 状态机与硬件音源，没有新增MCU或软核CPU。
- 沿用50MHz参考、两级PLL的标称49.152MHz音频时钟，以及48kHz / 24位Philips I2S、32位声道槽。
- 保留外置DAC引脚 BCK=Y21、WSEL/LRCLK=AB21、DIN=AA20；板载PT8211功放仍禁用。
- 新位流输出到独立`board16/impl`，既有四声部演奏和64音自检工程保留。

## 仿真和构建结果

事件发生器独立测试通过：`stop_positions=16 full_run=1 scenarios=17 stalled_cycles=215 reset_and_fault=covered`。覆盖全部加载中停止位置、握手反压、重复启动、完整释放、复位及错误清理。

完整板级集成测试通过：

```text
BOARD 16-VOICE 48K I2S PASSED held=16 on=48 off=16 slots=799 nonzero_slots=712 clipped=0 underruns=0 start/hold/stop/restart/reset/pll-loss
```

检查引擎实际接收的16个不同音符、持续保持的声部掩码、外部I2S时钟和32位槽格式、按KEY1停止并排空至数字静音、再次启动、KEY2复位与PLL失锁复位。3次启动共48条note-on，其中1次正常停止有16条note-off，另外2次由协调复位直接清空。仿真包络暂缩短为1/1/1ms，硬件仍为10/80/100ms。

Icarus编译器在沙箱内生成输出后异常退出；同一测试脚本在沙箱外正常编译并运行，退出码0。Gowin原厂PLL仿真库存在无敏感列表的既有警告。

Gowin V1.9.12综合、布局布线与位流生成成功：Setup/Hold违例端点均为0，音频域Fmax为76.165MHz，高于49.152MHz约束；Logic5159、Register3569、BSRAM72、DSP27、PLLA2。

位流：`board16/impl/pnr/BoardAudio16_48kI2S.fs`。

SHA256：`B257232DAE906F91BC5477ED12BDF93DC47B08D2854D09100702347F93B77997`。

构建保留既有EX2526 ROM文本位宽、固定表情优化NL0002、跨域时钟关系CK3000、参考时钟通用布线PR1014警告；未通过屏蔽警告修改已有音源。外部I2S模拟时序、实际参考频率和整机延迟尚未用仪器测量。
