# 16音逐个播放测试（2026-10-08）

## 操作与播放节奏

本入口按用户要求替代16声部同时保持测试。保留既有外置PCM5102A、PAM8403与喇叭的接线、供电。

- KEY0（AA13）：按一下，从MIDI60/C4开始逐个播放到MIDI75/D♯5，随后循环。无需按住。
- KEY1（AB13）：停止序列，释放正在发声的音符。
- KEY2（Y12）：复位静音。再次按KEY0从C4重新开始。
- 每个音保持400ms，再释放尾音；尾音回收后留100ms间隔，再触发下一个音。音高每次升一个半音，同时最多一个声部。
- 保留原10ms起音、80ms衰减、100ms全幅释放斜率；正弦保持幅度为0.75，所以稳定保持后的尾音通常约75ms。间隔计时从声部回收开始，I²S原有缓冲仍有数帧传输延迟。
- PWR是电源键，不能用作播放键。功放从低档开始，逐步调整音量。

## 工程与实现

工程`boardseq16/BoardSequence16_48kI2S.gprj`；顶层`rtl/board/board_sequence16_48k_i2s_top.v`；事件源`rtl/diagnostics/sequence16_event_source.v`。

事件源经既有分配器和音源的ready/valid接口按顺序发送note-on/note-off，等待释放完成后再计时进入下一音。停止时保持已经呈现的事件稳定，确保完成已接受音符的配对释放。运行中的重复启动不会重置序列。

固定正弦音色0、力度100、中性表情、关闭延迟效果。没有更改共享音源、波表、混音器或包络。全部由FPGA HDL逻辑实现，没有MCU或软核CPU。

沿用50MHz参考与两级PLL生成标称49.152MHz音频时钟，48kHz/24位Philips I²S、32位声道槽。外置DAC引脚BCK=Y21、LRCLK=AB21、DIN=AA20。独立输出目录保留原演奏和多声部自检工程。

400ms计时为19,660,800周期；100ms计时为4,915,200周期。常量计算使用64位中间结果，避免32位乘法溢出。

## 验证

事件源独立测试通过：34个音顺序正确（两个完整循环再播放两个音）、最多1声部；加速计时下最短保持49,157周期、静音49,154周期，均不小于配置49,152周期。覆盖启动/停止、阻塞期间ON/OFF负载稳定、间隔中停止、故障清理和协调复位。

完整板级测试通过：

```text
BOARD SEQUENCE16 48K I2S PASSED notes=16 wrap=1 max_voices=1 on=19 off=19 slots=405 nonzero_slots=140 quiet_slots=82 clipped=0 underruns=0 start/stop/restart/reset
```

测试仅加速事件计时和包络；保留真实音频时钟和I²S串行输出，检查16个不同音符均产生非零外部音频、回绕、静音间隔、停止、重启和复位。开发期间重启断言的初始等待短于I²S缓冲延迟，已将观察窗口扩大到8帧，最终完整测试退出码0。结果日志在`sim/test_board_sequence16_48k_i2s_results.log`。

Gowin V1.9.12综合、布局布线和位流生成成功：Setup/Hold违例均0；音频域Fmax73.964MHz，高于49.152MHz约束。Logic5153、Register3589、BSRAM72、DSP27、PLLA2。

构建保留既有EX2526 ROM文本位宽、固定表情优化NL0002、时钟关系CK3000、参考时钟通用布线PR1014警告；外部DAC模拟时序、实物频率和听感未在本测试中用仪器量测。

位流`boardseq16/impl/pnr/BoardSequence16_48kI2S.fs`；SHA256：`729E107A941ACC864C0A398E06FD653B02D40BD94C7C9C596CD2DB66ACB98134`。
