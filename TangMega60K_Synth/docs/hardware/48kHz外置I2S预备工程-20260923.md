# 48 kHz 外置 I2S 预备工程（2026-09-23）

`clock48/BoardAudio48kI2S.gprj` 是新建的独立板级入口。它复用现有 `live64_system_top`、24 位 Philips I2S 发送器和已验证的两级 PLLA 时钟；从板载 50 MHz 得到标称 49.152 MHz，左右声道各 32 位时隙，标称采样率 48 kHz、BCLK 3.072 MHz。按键 0 启动 64 声部自检，按键 1 停止，按键 2 复位。板载功放保持禁用；不驱动板载 PT8211。

该入口与已实测的 `clock48/BoardAudio48kGAO.gprj` 分开，原 GAO 位流 SHA256 仍为 `24454E10D54FF9A39069215ED7BB471A801949240597DC797A65547B50099031`。本入口位流为 `clock48/impl/pnr/BoardAudio48kI2S.fs`，SHA256 为 `A1A22BAE737FB4C7FF55D5E99455E9BB76E58D81F445A3EA363570B66677198A`。

## PMOD1 候选输出

按 NEO Dock 31004 Rev 1.4 原理图与官方引脚约束，`clock48/board48k_i2s.cst` 指定：

| FPGA 输出 | J8 针脚 | FPGA 球号 | 复用网络 |
| --- | ---: | --- | --- |
| `i2s_bclk` | 11 | Y21 | PMOD1_IO0 / CAM0_VSYNC |
| `i2s_lrclk` | 9 | AB21 | PMOD1_IO2 / CAM0_HSYNC |
| `i2s_data` | 7 | AA20 | PMOD1_IO4 / CAM0_D7 |

三脚均配置为 3.3 V LVCMOS、4 mA 驱动。J8 的 3、4 脚为 GND，1、2 脚为板载 3.3 V；后两脚**只能在到货 DAC 模块明确支持 3.3 V 供电时使用**。连接前须核对实物底板版本、J8 的 1 号脚方向，以及 DAC 模块的 BCK/LRCK/DIN 与供电说明。PMOD1 与 DVP 摄像头和 40P 扩展复用，不能同时连接其他驱动这些网络的设备。FPGA 信号脚不可接入 5 V。

## 已验证与未验证

- `scripts/test-board-48k-i2s.ps1` 使用高云 GW5A PLLA 仿真模型，检查 64 声部启动、按键停止后清空声部、再次启动、复位静音，以及 I2S 32 位声道槽、1 位延迟、7 位零填充和 BCLK 周期。复测记录 521 个完整声道槽、非零音频位 1024 个，第二次启动仍为 64 声部且欠载为 0。为缩短仿真耗时，测试台仅将 ADSR 释放时间覆盖为 1 ms；生成的板级位流仍使用原来的 100 ms 释放时间。独立 `tb_audio_clock_48k.sv` 的 3072 周期时长验证仍通过。
- 公共 I2S 发送器的 `tb_i2s_tx.sv` 还逐帧比对左右 24 位 PCM 与串行输出；本次单独重跑 V1 和 V2 两种接口模式，分别得到 `ALL I2S TESTS PASSED` 和 `ALL V2 I2S TESTS PASSED`。
- Gowin V1.9.12 对此独立入口完成综合、布局布线与位流生成。管脚报告为 Y21、AB21、AA20；内部 Setup/Hold 违例端点均为 0。输入 V22 的 PR1014 告警仍在；综合阶段的 CK3000 时钟关系提示也存在于原 GAO 工程，跨域控制使用首级同步寄存器约束。静态时序通过不代表板外信号已测量。
- **本外置 I2S 入口尚未下载到实物或连接 DAC。** PCM5102A 模块尚未到货。外部 BCLK/LRCK/DATA 的电压、边沿、布线延迟、DAC 模拟输出和实际绝对采样率均待上板验证。`board48k_i2s.sdc` 检查片内时钟路径；DAC 输入的外部 setup/hold 仍需依据实物连线与模块手册核对。
- 当前板子已重新接入 12 V 并开机。Gowin Programmer 经 DEBUG USB 识别 GW5AT-60B（ID `0x0001481B`）；已将原 GAO 位流 `ao_0.fs` 下载到 SRAM，程序回报 `Finished`，独立复读 User Code `0x000099EE`、状态码 `0x70026020`。这验证了供电、JTAG 通信和原 GAO 配置，**不代表新的外置 I2S 引脚或 DAC 已经过实测**。SRAM 配置断电后不保留。
