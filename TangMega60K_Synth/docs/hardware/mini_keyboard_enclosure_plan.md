# 25键小电子琴：外壳尺寸与布局基准

> 2026-09-16状态更新：25键裸键床货源尚未落实，此方案暂存为机械草案，不据此采购或加工。现阶段优先评估自研和弦/演奏垫面板；见`../赛题核查与下一步计划-20260916.md`。下文尺寸不代表已选定成品。

## 推荐尺寸与适用条件

第一版推荐外壳外尺寸：**400 mm（左右宽）×280 mm（前后深）×80 mm（壳体高）**。
高度不包含突出壳体的旋钮帽、脚垫；携带包装应再核对整机最高点。

适用配置：Tang Mega 60K核心板+NEO Dock、25个迷你黑白琴键、表情控制条、
少量旋钮/指示灯、两只小扬声器。电源适配器放在外部，当前不预留内置电池。
64复音是内部合成目标，不决定琴键数或外壳尺寸。

这是可供选型和纸板样机使用的尺寸基准，**不是已经完成干涉检查的加工图**。
尚未选定键床、扬声器和散热器，也未测量用户实物底板版本；因此暂不提供孔位和开孔尺寸。

## 空间分配（设计预算，不是已购零件的实测尺寸）

以下尺寸按3 mm壳壁估算，内部净空间约394×274×74 mm，暂不计加强筋占位。

| 区域 | 建议预留空间 | 选型/安装条件 |
| --- | --- | --- |
| 前部25键键床 | 330×130 mm平面区域 | 选键床总成而非只量露出的键面；整体含支架、触点和运动包络须放得下，安装高度预算不超过45 mm |
| 后部中央板卡区 | 180×120 mm平面区域 | 包括129×84.51 mm PCB板边包络和接口走线；完整安装高度预算不超过60 mm，按真实插头弯曲空间复核 |
| 后部左、右扬声器区 | 各60×60 mm | 驱动单元加安装结构和声学空间须共同检查；初步限制安装总深度不超过35 mm，不能仅按标称口径选型 |
| 前部侧边表情控制区 | 约20×100 mm | 预留压力条/滑条；引线及辅助电路不侵入键床活动区 |
| 面板控制区 | 少量旋钮、音色和八度按钮、指示灯 | 布置在后部非散热器位置，核对旋钮/显示模块向下伸出的体积 |

前后预算：130 mm键床区+10 mm隔离走线带+120 mm板卡区=260 mm，
小于274 mm内部净深。后部左右预算：60+20+180+20+60=340 mm，
小于394 mm内部净宽，余量用于壳壁附近固定结构和布线。
这仅证明矩形区域可排入，不代表具体零件已经验证无碰撞。

## 装配要求

1. 键床放前部、开发板放后部，先采用互不重叠的安装方式。
2. 支柱只固定在已核对的板卡安装孔；使用独立托板，避免把键床按压力传给开发板。
3. 核对散热器上方净空并设置通风孔，导线避开琴键行程和散热区域。
4. 板卡接口分布在不同板边，后侧/侧面开口要按板卡朝向设计；若加延长线，应计入插头体积和弯曲空间。
5. 扬声器不能仅挤入一个孔位：还要留磁体、接线和固定空间，音质需要装配后试听。
6. 先做1:1纸板底面样机，按400×280 mm外轮廓、3 mm壳壁摆入实物，插上所需线缆并按遍琴键。

## 尺寸定稿前需要的资料

- 25键键床的总宽、总深、安装孔位、最大运动包络和触点接线资料。
- 实物NEO Dock版本以及装好核心板、散热器、支柱和插头后的最大尺寸。
- 扬声器外框、磁体深度、面板控制模块的背部尺寸。

满足上述预算后维持400×280×80 mm；有任何组件超限时，调整外壳或零件选型后再下单加工。
现阶段可以据此给队员确定产品体量、寻找键床和制作纸板样机。
