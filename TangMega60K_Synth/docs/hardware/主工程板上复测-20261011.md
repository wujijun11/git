## 实物结果

| 检查 | 结果与来源 |
| --- | --- |
| KEY0 启动、播放中停止、再按重播 | 用户报告通过 |
| KEY2 按下并松开复位，再按 KEY0 | 用户报告可重新播放 |
| 播放中按 KEY1 | 用户报告乐曲停止 |
| 再按 KEY1 退出引导，再按 KEY0 | 用户报告可重新播放 |
| 喇叭实际输出 | 用户报告“声音很轻，但能听到音高变化” |

原话为“能播放、停止、重播，复位后也能重播”和“KEY1 能停止乐曲，退出后 KEY0 能重播”。结构化结果见 [本次板上复测记录](../../verification/contest-full-20261011/hardware-main-controls-retest.json)。没有外接灯条，本次 KEY1 结果仅证明声音控制和恢复，不证明指引灯输出正常。

声音偏轻尚未解决。代码中主工程 `MASTER_SHIFT=1`，单声部诊断为 7；同一单音的数字尺度差 64 倍（约 36.1dB），主工程保留了多声部叠加余量。本次没有改变混音增益，也没有测量模拟输出电平、精确音高或失真，不能据此宣布旋律和音质验收通过。

## 尚未实测的功能

25 键琴键 PCB、滑条、ESP32-C3 和外接 WS2812 尚未到货。用户确认没有 HDMI 显示器和 3.3V USB 转 TTL；电脑仅枚举到蓝牙虚拟 COM5，不能当作 FPGA 的 UART 使用。现有主工程没有可用的内嵌 GAO，DEBUG USB 的读码不能替代内部遥测。

因此，25 键/滑条、手机 BLE、外接 LED、HDMI、64 声部实际并发、运行时音色/音效，以及控制到 DAC 的物理延迟仍待验收。现有仿真通过记录继续作为软件证据，不能标为以上实物功能已经通过。整机接线与后续步骤见 [首次上板与到货验收](../全功能首次上板步骤-20261011.md)。
