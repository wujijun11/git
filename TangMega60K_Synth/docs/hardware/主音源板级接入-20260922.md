# 主音源板级数字自检接入

入口为 `BoardAudioDiagnostic.gprj`，顶层 `board_audio_diagnostic_top`。它直接实例化既有 `live64_system_top` → `audio_system_v2`，复用64声部分配、DDS、ADSR、混音及24位标准Philips I2S发送器，不是另写一个演示音源。正常演奏接口及音源算法未改；没有恢复PT8211模式。

## 操作和连接

使用50MHz板载时钟V22；key_n[0/1/2]对应AA13/AB13/Y12，采用LVCMOS15。RGB为J16；AB16保持高电平禁用板载功放。外置DAC未到货，本入口不向外部连接器输出I2S，也不使用板载PT8211。

| 控制 | 行为 |
|---|---|
| key_n[0] | 消抖后启动64音自检；一次按下只触发一次 |
| key_n[1] | 停止，发出note-off并等待全部尾音回收 |
| key_n[2] | 复位音源、控制器及诊断状态 |
| 绿灯闪烁 | 待机 |
| 蓝灯 | 正在启动或释放 |
| 青灯 | 64声部保持，且本轮观察到非零串行数据 |
| 黄灯 | 64声部保持，但本轮尚未观察到非零串行数据 |
| 红灯 | 分配错误或额外I2S欠载，复位清除 |

启动时发送器先输出一个零帧，首个样本尚未就绪，因此允许一次启动欠载；后续欠载触发故障。青灯只证明上述运行条件，不证明音质、64个频谱峰或所有I2S位均正确。位序和样本一致性由仿真接收器检查。

## 时钟边界

当前仅为50MHz数字自检。每帧1024时钟，实际采样率48,828.125Hz，BCLK为3.125MHz。原音源查表按48kHz生成，因此此入口不能作为已校准音高的48kHz发声版本。原49.152MHz音频入口保持不变；外接DAC前仍需完成音频时钟与引脚约束。

## 复现

在项目根目录执行：

```powershell
& 'C:/Gowin/Gowin_V1.9.12_x64/IDE/bin/gw_sh.exe' scripts/build-board-audio.tcl
```

脚本显式设置顶层。若在GOWIN界面打开工程，请选择 `board_audio_diagnostic_top` 作为顶层，不要选择 `audio_system_v2`。

仿真运行 `scripts/test-board-audio.ps1`，需Icarus Verilog位于C:/iverilog/bin。测试真实音源数据经过I2S编码后，检查Philips一位延迟、24位数据、32位槽、填零和逐样本一致性，以及64声部启动、停止回收、重新启动、复位恢复。
