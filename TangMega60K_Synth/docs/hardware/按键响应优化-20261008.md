# 板载演奏按键响应优化（2026-10-08）

## 修改范围

`rtl/board/board_instrument_b_48k_i2s_top.v` 的默认 `DEBOUNCE_CYCLES` 从 500000 改为 100000。底板时钟为 50MHz，因此连续稳定等待由 10ms 降为 2ms，为音源调度、I2S 与外置 DAC 留出响应预算。

输入的两级同步、逐键独立稳定计数、跨音频时钟域同步、事件队列和松键回收继续使用既有实现。KEY0 演奏钢琴 A4，KEY1 演奏 C 大三和弦，两键同时按为四声部；KEY2 复位静音。音源、音色、包络和既有外置 DAC 引脚没有变化。钢琴门控起音使用专用 2ms 分支，释放仍使用 `RELEASE_MS=100` 的全幅斜率；尾音时长会随松键时的幅度改变。

共享 `board_bringup_top` 和独立的 16 音诊断工程仍保留原来的默认参数。修改仅作用于 `boardkeys48/BoardInstrumentB48kI2S.gprj` 演奏入口，全部逻辑由 FPGA HDL 实现。

## 验证范围

新增 `sim/tb_board_key_latency.sv` 与 `scripts/test-board-key-latency.ps1`，不覆盖演奏顶层的消抖和 ADSR 参数，通过原厂 PLL 模型生成标称 49.152MHz 音频时钟。专项测试记录输入引脚、消抖输出、音源命令握手和完整解码的首个非零 24 位 I2S 样本时间。

测试覆盖短于阈值的毛刺、间断弹跳、按住不重复、松键事件与尾音、同时按两键的四声部命令以及 KEY2 复位，并在三个采样时刻检查冷启动单音响应。测得的最大值只代表这些仿真场景，不代表所有机械按键弹跳或所有时钟相位的最坏情况。

既有完整板级回归已通过：接受 72 条命令、解码 1183 个声道槽、6972 个非零有效数据位，欠载为 0。覆盖单音、三和弦、四声部、独立松键、尾音重按、复位恢复、保持按键时复位、PLL 失锁恢复、队列溢出静音及 KEY2 恢复。该功能回归仍使用消抖 8 周期和释放 1ms 的加速配置，只证明逻辑功能；数字延迟以新增的真实默认参数专项结果为准。

专项仿真通过，退出码 0，保持真实默认消抖和包络参数。输入引脚稳定改变后的测量结果如下：

| 测量项 | 仿真响应时间 |
| --- | ---: |
| KEY0 消抖输出 | 2.000030ms |
| KEY0 命令握手，三个冷启动采样时刻 | 2.001461 / 2.001464 / 2.001456ms |
| 首个完整非零 24 位 I2S 样本，三个冷启动采样时刻 | 2.285207 / 2.292900 / 2.286055ms |
| KEY0 松键命令握手 | 2.001467ms |
| 同时按两键，第四个音的命令握手 | 2.053302ms |
| KEY2 复位 | 2.000068ms |

三个采样时刻中测得的最大 I2S 响应为 **2.292900ms**。100μs 和 1.9ms 的三键短毛刺、间断弹跳、按住无重复、松键尾音、四声部归属及复位静音均通过。总计解码 2095 个声道槽，其中 978 个非零，欠载为 0。

```text
BOARD KEY LATENCY PASSED production_debounce=100000 production_ADSR=10/80/100 ms glitch_filter=100us/1.9ms bounce_filter=1 held_no_repeat=1 on=7 off=1 reset_silence=1 slots=2095 nonzero_slots=978 underruns=0 scope=simulation_input_pin_to_I2S_only
```

日志为 `sim/key_latency_results.log`，属于本地生成物；Git 保留可复现的测试源文件和脚本。上述 `production_ADSR` 字段是全局参数核对，钢琴实际起音使用前述专用 2ms 分支。

## 复现与实物验收

在 `TangMega60K_Synth` 目录运行：

```powershell
& .\scripts\test-board-key-latency.ps1
& .\scripts\test-board-instrument-b-48k-i2s.ps1
& C:\Gowin\Gowin_V1.9.12_x64\IDE\bin\gw_sh.exe scripts/build-board-instrument-b-48k-i2s.tcl
```

本机 Icarus 的沙箱限制与已有测试相同，需使用本轮验证允许的执行环境。工具路径换机后需按实际安装位置调整。

2ms 连续稳定过滤不能保证所有实体机械按键都无重复触发。若机械弹跳中出现持续 2ms 或更长的反向稳定状态，仍可能产生额外按放事件；上板后需检查快速连击、按住、松开和同时按键，并根据实测调整该参数。

仿真只测输入引脚到 I2S 数字输出，不包含实体传感器内部处理、机械接触变化、DAC 数字滤波、功放和扬声器。赛题要求的输入到音频输出总延迟不超过 10ms，仍需接入最终演奏面板后进行端到端实测。
