# 60K 板级验证入口（2026-09-22）

用户当前没有外置 I2S DAC。本次新增独立 `BoardBringup.gprj`，不改音源、控制器或 I2S 公共接口，不恢复 PT8211 模式。

## JTAG 已完成

GOWIN Programmer V1.9.12：选 `USB Debugger A/1/609/null`、2.5MHz、勾选 using ftd2xx driver。当前 USB 位置可能随重新插拔变化。
扫描找到 1 个器件，按实际 60K 型号选择 GW5AT-60B；Read Device Codes 完成：ID=0x0001481B，User Code=0x0000A937，Status=0x70026020。
这些读数证明 JTAG 通信成功，不证明本项目已经烧录或音频通过验收。

## 独立板级工程

- 顶层：`board_bringup_top`；器件 GW5AT-LV60PG484AC1/I0，B 版。
- 50MHz：V22，3.3V。
- 三个用户按键：AA13、AB13、Y12，BANK9 1.5V 内部上拉，低电平有效。两级同步和约10ms消抖。
- WS2812：J16，3.3V。默认暗绿色每秒闪烁一次；按键0/1/2分别点亮红/绿/蓝，支持混色。按键编号按球号定义，不凭照片左右位置猜测。
- PA_EN：AB16，固定高电平，关闭板载功放；不输出音频。
- 供电启动等待65535周期，WS2812高电平0.4/0.8us、位周期1.26us，帧间低电平约20ms。

约束依据官方60K pin map及NEO Dock 31004原理图。实物照片可见31005字样，完整版本差异尚未逐项比对；这里仅使用官方共用底板的时钟、用户键和彩灯信号，完整外设接线仍待核实。

## 验证

从工程根目录运行：

```powershell
& C:/iverilog/bin/iverilog.exe -g2012 -s tb_board_bringup -o sim/board_bringup.vvp rtl/board/board_bringup_top.v sim/tb_board_bringup.sv
& C:/iverilog/bin/vvp.exe sim/board_bringup.vvp
& C:/Gowin/Gowin_V1.9.12_x64/IDE/bin/gw_sh.exe scripts/build-board-bringup.tcl
```

仿真已通过 `BOARD BRINGUP TESTS PASSED`：启动、功放关闭、短毛刺过滤、稳定按键、组合按键、释放、GRB串行顺序及高电平宽度。测试将消抖缩短为8周期，未模拟人体按键或测量实际50MHz。

GOWIN完成综合、布局布线和码流生成。50MHz约束下 setup/hold违反端点均为0；报告Fmax约146.501MHz；262逻辑单元、148寄存器。
保留PR1014警告：V22时钟使用普通布线资源。尝试BUFG约束不能改变该结果，已移除无效约束；当前小型单时钟诊断的布线后时序通过，但此结果不能外推到完整音源。正式音频仍需独立设计PLL/音频时钟方案。
命令行另提示无权限写用户目录的sh.log；项目目录内综合、布线和时序报告已正常生成。
