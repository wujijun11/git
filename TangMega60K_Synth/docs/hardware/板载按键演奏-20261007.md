# 板载按键演奏（2026-10-07）

## 目的与操作

外置 PCM5102A、PAM8403 功放及喇叭已在旧自检程序下由用户确认发声、停止、再次启动和复位正常。本次新增板载演奏入口，将真实按键的按下与松开事件接入队员 B 的 `instrument_system_v2`，使用队员 A 的八成分钢琴音色 2，通过既有外置 I2S 接线发声。

| 按键 | 按住 | 松开 |
| --- | --- | --- |
| KEY0（AA13） | 钢琴 A4，MIDI 69 | 释放该单音 |
| KEY1（AB13） | 钢琴 C 大三和弦，MIDI 60/64/67 | 释放该和弦 |
| KEY0 + KEY1 | 单音与和弦共四声部 | 各键只释放自己触发的声音 |
| KEY2（Y12） | 复位静音并清除待发事件 | 允许继续演奏 |

硬件保留约 100 ms 的包络释放，松开有自然尾音。按住 KEY0/KEY1/KEY2 时 RGB 分别显示红/绿/蓝；同时按 KEY0 与 KEY1 会组合红绿。PWR 是电源按键，不在演奏键中。

## 工程

- 工程：`boardkeys48/BoardInstrumentB48kI2S.gprj`。
- 顶层：`rtl/board/board_instrument_b_48k_i2s_top.v`。
- 按键事件适配：`rtl/board/board_key_event_adapter.v`，保存按下/松开顺序并保持 ready/valid 握手；若待发队列溢出，复位音源保持静音，按 KEY2 可恢复。
- 构建：在工程根目录运行 `gw_sh.exe scripts/build-board-instrument-b-48k-i2s.tcl`。
- 仿真：`scripts/test-board-instrument-b-48k-i2s.ps1` 与适配器独立测试。
- 使用独立 `boardkeys48/impl` 输出，保留 `clock48` 已验证的自检位流。
- 复用 `clock48/board48k_i2s.cst` 与 `.sdc`，BCK=Y21、WSEL=AB21、DIN=AA20。
- 50 MHz 参考、两级 PLL 得到标称 49.152 MHz 音频时钟，48 kHz/24 位 Philips I2S，32 位声道槽。

新增入口为 FPGA HDL 状态机、FIFO 与硬件音源；没有软核 CPU 或 MCU 程序。两个板载演奏按键均属于选音/触发交互，最终仍需 B 接入实体演奏面板和独立压力或滑条等表情输入，落实赛题的两种独立演奏维度。

- 完整板级集成仿真：通过，音频引擎接受 72 条命令；外部 I2S 解码得到 1183 个完整 32 位声道槽、6972 个非零有效数据位，欠载计数为 0。覆盖单音、三和弦、四声部、分别松键、尾音期间重按、KEY2 清除及保持演奏键后的恢复、PLL 失锁恢复、输入队列溢出静音及复位恢复。仿真将释放时间缩短为 1 ms；实物位流保留 100 ms。
- Gowin 综合与布局布线：通过；Setup/Hold 违例端点均为 0。报告识别音频时钟为 49.152 MHz，音频域 Fmax 为 68.711 MHz；资源为 Logic 5406/59904、Register 4006/60780、BSRAM 72/118、DSP 27/118、PLLA 2/8。

## 下一阶段交接

保留本工程作为已下载、已完成试听的板载按键基线。下一阶段由 B 交付实体演奏按键的扫描/去抖及独立表情输入的采集/滤波/标定，队长将其接入既有 `instrument_system_v2` 的 `key_*`、`chord_*` 与 `expr_update_*`。两个板载演奏键仍属于同一触发维度；本次试听完成不代表独立表情输入已完成。

B 的硬件接口需同时给出外设型号、供电与信号电平、引脚表、工作时钟和复位方式。事件及表情数据在 `valid && ready` 的时钟沿传输，等待 `ready` 时保持负载不变；跨域多位数据使用整包握手或异步 FIFO。具体外设引脚在交付资料确认后分配，现有 DAC 的 Y21/AB21/AA20 接线继续复用。

本次采用 SRAM Program，断电后需重新下载同一位流。

本次构建保留既有警告：`EX2526` 提示 ratio ROM 的 7 位十六进制文本与 27 位存储宽度不同，32 项最大值 55805283 小于 2^27，没有有效位截断；`NL0002` 是固定表情输入下表达式模块被优化；`CK3000` 提示工具不能计算 50 MHz 与音频时钟的关系，跨域信号使用同步寄存器；`PR1014` 仍提示 V22 参考时钟输入采用通用布线，详见 [既有调查](PR1014-clock-investigation-20260922.md)。这些警告未被屏蔽，静态时序通过仍需结合实物确认。

外部 I2S 时序和参考时钟的绝对频率仍未进行仪器测量，沿用既有工程记录中的限制。
