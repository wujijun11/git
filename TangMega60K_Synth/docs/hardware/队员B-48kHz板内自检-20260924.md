# 队员 B：48 kHz 板内数字自检

独立工程 `clock48/BoardInstrumentB48kGAO.gprj` 将队员 B 的 `instrument_system_v2` 接到已验证的 50 MHz → 38.4 MHz → 49.152 MHz 两级 PLL 时钟。上电后自动发送一个钢琴音符（69）、一个三音和弦（60/64/67）及增益/弯音/颤音表情快照，再发送和弦与单音松开。所有 `valid` 在对应 `ready` 握手前保持不变；每轮核对事件 FIFO 守恒、4 个活动声部、非零 I2S 数据、零欠载、零溢出，等待全部声部释放后自动重启。KEY2 可手动重启；这里的 KEY2 是底板普通按键，不是电源 PWR 键。

这份工程只在片内通过 GAO 观察标准 24 位 Philips I2S，不接外置 DAC。PMOD1 没有被驱动，板载功放保持禁用。到货的 PCM5102A 尚未接线；模拟声音、外部数字信号电平与 DAC 供电留待单独验证。此自检会经过 B 的输入处理和 A 的音色 2，但使用内部自动事件，不能代替实物键盘/传感器测试。

复用 `constraints/board_bringup.cst`：板载时钟 V22，三个 1.5 V 低有效按键 AA13/AB13/Y12，WS2812 数据 J16，功放禁用 AB16。GAO 配置在 `clock48/board_instrument_b_48k.rao`，采集 `phase`、`completed_runs`、`fault`、`active_count`、低 8 位欠载和事件计数、FIFO 深度及片内 I2S。WS2812 蓝色表示本轮运行中，绿色表示至少完成一轮，红色表示自检故障；状态从音频时钟域以两级寄存器同步到 50 MHz 域。颜色只是辅助显示，判断结果以 GAO 为准。

& 'C:/Gowin/Gowin_V1.9.12_x64/IDE/bin/gw_sh.exe' scripts/build-board-instrument-b-48k-gao.tcl

Icarus 板级测试连续完成两轮，覆盖按键事件保存的音符/音色、和弦扩展与释放、表情快照、I2S 时钟与非零数据、KEY2 重启；测试台仅将 ADSR 释放从硬件的 100 ms 缩短为 1 ms。输出为 `BOARD B 48K GAO PASSED runs=2 on_mask=15 off_mask=15 data_ones=30304 lrclk_edges=232`。

Gowin V1.9.12 综合、布局布线和位流生成通过；Setup/Hold 违例端点均为 0。布局布线报告为 Logic 6184/59904、寄存器 4555/60780、BSRAM 88/118、DSP 27/118、PLLA 2/8，音频时钟域 Fmax 71.819 MHz，高于目标 49.152 MHz。布线仅出现已知的 V22 非专用时钟输入 `PR1014`；综合仍提示两个时钟的 `CK3000` 关系不明，跨域标志已做两级同步并对首级设例外。外部 50 MHz 晶振的绝对频率仍未实测。

## 2026-09-24 实板验证

用户确认底板已使用稳定的 12 V 电源，核心板指示灯持续亮。Gowin Programmer 经 DEBUG USB 扫描到 1 颗 `GW5AT-60B`，器件 ID 为 `0x0001481B`。下载前 User Code 为 `0x0000A937`；将上述 SHA256 的新位流下载到 **SRAM** 后，工具返回 `Finished`，重新读取 User Code 为 `0x0000E524`，状态码为 `0x70026020`。这次没有写入 Flash；断电后需重新下载，或另行执行 Flash 烧录。

随后从 Gowin FPGA Designer 打开本工程的 GAO，使用 `Gowin USB Cable(FT2CH)`、`Location:609` 两次采集板内信号。两次均读到 `pll_locked=1`、`serial_seen=1`、`fault=0`、`event_overflow_sticky=0`、`underruns[7:0]=0x00`，事件已推入/送达均为 `0x08`，FIFO 深度为 `0x00`。低 8 位 `completed_runs` 两次分别为 `0xE0` 和 `0x7C`；它在重复自检中循环计数，因此数值回绕不表示倒退。采样瞬间 `phase=0xB`（等待声部释放）、`active_count=4`，属于该轮仍在进行的状态；已完成轮数非零且两次不同，证明此前有完整轮次通过并持续运行。该采集支持 **板内 B 输入事件 → FIFO → A 音源 → 数字 I2S** 链路通过，不代表外部 DAC 模拟声音或真实键盘输入已验证。
