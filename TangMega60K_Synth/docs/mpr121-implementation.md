# MPR121 25键与四电极滑条 RTL 实现

核对与仿真日期：2026-10-11。新增 `rtl/sensors/` 已通过 Icarus Verilog 2005 编译、四组总线/事件/默认时序仿真和高云默认参数独立综合。尚未做本模块独立布局布线、实板下载、装配阈值校准或延迟实测；本文件不指定实际管脚。完整工程的综合及布局结果由整机报告另行记录。

## 官方依据与明确的初始化

已直接阅读 [NXP MPR121 Rev.4（2013-02）](https://www.nxp.com/docs/en/data-sheet/MPR121.pdf) 的寄存器表、§4.5、§5.1–5.4、§5.8–5.12；同时核对 [AN3895 串行通信](https://www.nxp.com/docs/en/application-note/AN3895.pdf) 及 [AN3944 初始化指南](https://www.nxp.com/docs/en/application-note/AN3944.pdf)。连续读取 `0x00–0x2A` 共43字节，数据来自一次完整快照；filtered 为10位，baseline读数左移2位后才能相减。SCL最高400kHz，低电平至少1.3μs。最后一个读字节由主机发送NACK，属于正常结束。

每块独立执行软复位 `80=63`，等待默认1ms，Stop `5E=00`，写入并逐项读回：

| 寄存器 | 默认写值 | 意义 |
|---|---|---|
| 2B–35 | 01,01,00,00,01,01,FF,02,00,00,00 | 上升/下降/已触摸基线滤波 |
| 41–58 | 每电极touch=12、release=6 | ELE0–11独立阈值 |
| 5B | 00 | 触摸/释放消抖设置 |
| 5C / 5D | 10 / 20 | 全局CDC16µA、CDT0.5µs、ESI1ms、SFI4 |
| 76 / 77 | 00 / 00 | GPIO输入方向、GPIO禁止 |
| 7B / 7C | 00 / 00 | 自动配置与重配置明确关闭 |
| 5E | 8C / 88 / 89 | 三块启用12/8/9个连续电极、CL=10、近接关闭 |

除只写软复位寄存器外，上表和Stop写入均读回比较。阈值、CDC/CDT为调试候选，可以通过参数修改；这些值没有通过当前铜面、膜、线束和功放环境实测。

最后启动后，默认先等待50ms，再等待3个连续无人触摸、有效baseline/filtered快照。所有启用通道必须处于释放状态，baseline和filtered必须非零、filtered不得到达上端限值，signed delta在±32内，才使对应`ready`为1。启动时按住或通信恢复后仍按住，会保持未就绪，直到检测到释放并完成校准。恢复不会直接重发持键。

## 模块与接口

`mpr121_input_frontend` 只使用共同的 `clk/resetn`，默认49,152,000Hz。三路`scl[2:0]/sda[2:0]`是开漏inout，只拉低或释放，必须配合外部3.3V上拉。三条电气独立总线允许地址均为5A，`ADDR0/1/2`可改为实际ADDR接法。`irq_n[2:0]`由上游板级同步器提供；本层检测低电平，同时定期轮询，常高/常低IRQ都可继续采集。

`key_map_flat[174:0]`的第k项在`[7*k +: 7]`，共25个MIDI音符。默认映射应由上游提供60..84；`current_timbre[1:0]`决定新按下的音色。KEY输出为`key_valid/ready,on,source[5:0],note[6:0],velocity[6:0],timbre[1:0]`。键号k对应source`25+k`，即25..49；source0..24保留给曲谱事件，source63用于手机。按下时保存note/timbre，改映射后释放仍匹配原来的音符。力度固定100，这不是压力或真实击键速度测量。

三模块键状态组合为`{MPR3[8:0],MPR2[7:0],MPR1[7:0]}`。MPR1 ELE8..11仅进入滑条，不触发额外音符。每模块提交各自最后成功读取的数据，不声称三块来自同一采样时刻。

输出表情为`expr_update_valid/ready`，`expr_update_mask=010`，`expr_update_bend_cents`为signed13位；未选中的`expr_update_gain_q1_11=2048`、`expr_update_vibrato_depth_cents=0`始终合法。该弯音是全局弯音。手机控制可另外提交gain、bend、vibrato三个独立表情字段；这证明三维表情控制逻辑接口，不代表本触摸面板采集了三个独立物理动作。当前实体方案只定义键盘选音/触发与滑条位置两个物理维度；真实力度/压力检测没有实现，velocity100不计为压力维度。正式演示仍须验证这两个物理维度可以独立操作，并验证手机表情联动。

遥测：`touch_mask[24:0]`、`ready/fault[2:0]`、`event_overflow`、`pending_events[15:0]`、每模块`last_error[3:0]`、32位`error_count/last_success_age`、5位`init_stage`和16位`oor_status`，以及`slider_active/slider_position[11:0]`。多模块总线打包以模块0占最低位。

| last_error | 原因 |
|---|---|
| 0 | 成功或尚无错误 |
| 1 | 从机地址/寄存器/数据阶段NACK |
| 2 | 整笔事务超时，包括clock stretching超时 |
| 3 | 总线一直忙，无法产生START |
| 4 | 静态寄存器读回与配置不符 |
| 5 | OVCF过流，锁存直到系统reset |

`init_stage`：0写配置、1等写完成、2读回、3等读回、4复位等待、5校准/轮询间隔、6发起快照、7等快照、8保留完整快照、9故障后重试间隔、10过流锁存。`last_success_age`是距最后完整成功快照的周期数，饱和32位；初始阶段也递增。

## 背压和故障

`i2c_register_master`锁存整个命令，支持随机读的重复START、逐字节ACK检查、最后NACK、真实SCL输入检查及有界clock stretching。I²C输入经过两级同步，实际总线速率略低于名义400kHz；默认低周期满足1.3µs，高周期和同步裕量满足规范。本层是单主机，不实现多主机仲裁。进入事务时若SCL高而SDA持续低，尝试一次九脉冲总线清除和STOP，处理复位中断从机读出的情况；整笔超时仍覆盖恢复流程，永久拉低报告错误并释放驱动。

默认整笔事务限时5ms，轮询间隔0.5ms（`POLL_CYCLES=CLK_HZ/2000`，从上一完整快照被事件层接受后计时，不等于每0.5ms取得一个快照）。一次读失败只丢弃scratch，不提交部分状态；默认最多2次额外尝试，仍失败使该模块离线。配置失败直接离线，每100ms尝试完整重新初始化。过流立即离线并锁存，不盲目清除过流；检查REXT后需要系统reset。OOR/ACFF/ARFF被记录；当前自动配置关闭，因此不把这些位当任意噪声报警使用。

事件FIFO默认64项。每次正常模块变化最多9项，接受前预留9项；多个模块故障的释放批次最多25项，预留25项。未提交模块快照保持完整且稳定；队列中的每次按下/释放按序保留。扫描期间收到故障时，先完成已承诺批次，再追加该模块的释放。健康模块持续持键不被清除。valid高而ready低时KEY及表情所有字段均保持不变。`event_overflow`锁存内部容量违规；整机必须将它接入明确panic/reset路径，不能忽略。合法FIFO参数（深度至少32）和预留机制使该状态在正常工作中不可达。

事件接收长时间背压时，各采样器会停在完整快照保留状态，新轮询和离线检测也会延后；`last_success_age`可识别这个停滞。这是有限存储的明确行为，不保证无限背压期间观测每个物理边沿。触摸硬件本身只有当前状态，因此轮询之间完成的极短按下/释放也无法恢复。已经采集并承诺的note-off不会被覆盖。

## 滑条

每路先用signed `delta=(baseline8<<2)-filtered10`减去噪声门槛，再把负值夹0，乘Q8归一化增益。默认每路噪声4、增益256、总权重门槛12。需要至少一个ELE8–11触摸位且总权重足够；否则松手回中。

位置采用权重质心，0/1024/2048/3072四个坐标。除法器先用32周期计算质心，再用32周期计算端点归一化后的弯音，中间夹紧、分子生成和最后迟滞各有寄存阶段，共约67周期（1.364µs）。这样消除了末周期质心除法、组合常量除法和迟滞连在一起的长路径。`SLIDER_POSITION_MIN/MAX`用于装配端点归一化，默认0/3072；`SLIDER_BEND_MAX`默认±200音分，默认中点死区3音分、位置迟滞2音分。参数应满足端点`MAX>MIN`且位于0..3072，噪声0..1023、Q8增益0..1024；新数据间隔应超过67周期（43字节I²C采样天然满足）。

表情背压时保留已呈现的payload，并保存最新目标弯音；尚未呈现的连续位置变化可合并为最新目标。松手/MPR1故障把目标置0；接收方恢复后收到最新中心值。双指只产生合成质心，不能区分多指或测真实压力。位置单调性、端点和实际噪声门槛须在最终装配后测量。

## 默认参数的条件时序预算

预算只讨论初始化/无人触摸校准结束后的运行，假设3个模块通信健康、没有clock stretch、SDA/SCL理想上拉、KEY/表情接收不背压，FIFO无历史积压。初始化默认含多次50ms基线等待，因此不在演奏响应预算内。

| 环节 | 默认理论/RTL数值 | 边界 |
|---|---|---|
| 43字节I²C随机读 | 1.062968ms（RTL 52,247周期） | 3条总线并行，不相加成3.19ms |
| 周期轮询间隔 | 0.500ms | 从上一快照接受后开始计时；完整读取与间隔合计约1.563ms |
| 已形成的新寄存器状态到提交 | 保守`2*1.062968+0.5+100/49152`≈2.628ms | 更新刚错过当前一致快照，需要完成本次、等下一次轮询再读；100周期含三模块事件扫描余量 |
| 健康低IRQ加速路径 | 保守`2*1.062968+100/49152`≈2.128ms | 新触摸/释放IRQ能提前下一次轮询；同电极内滑动或漏IRQ不能使用此界 |
| 滑条计算 | 约67周期=1.364µs | 加在已提交滑条快照之后，另有表情仲裁/音频边界 |
| MPR内部过滤 | SFI4×ESI1ms=4ms；按AN3890模型作约6ms的保守响应估计 | 不能把ESI1ms解释为物理响应1ms；真实阈值跨越还取决于电极、触摸幅度及噪声 |

过滤估计依据 [NXP AN3890，§末尾响应时间说明](https://www.nxp.com/docs/en/application-note/AN3890.pdf)：第二级滤波的更新时间为SFI×ESI，并描述其最坏情形为完整当前周期加半个前周期；应用到这里4ms得到约6ms。此处为对厂家模型的推导，不是本面板物理上限认证。

按这个保守模型，低IRQ键触摸路径在音频流水线之前约8.13ms；漏IRQ/只周期读取的路径约8.63ms，再加滑条与音频/DAC延迟。缩短轮询等待只降低数字调度预算；`5D=20`仍是SFI4、ESI1ms，不能通过写入不存在的更短合法SFI/ESI来承诺物理≤5ms。因此默认方案不能仅凭本预算宣称所有路径≤10ms，更不能宣称≤5ms或无抖动。I²C轮询和MPR更新相位本身产生可变等待。整机需结合实测选择采样参数/轮询间隔，分别量键盘、滑条、模块故障和最坏和弦流量。持续背压、无限clock stretch或错误重试不具备上述正常运行有限界；前者明确暂停采样，后两者由5ms事务超时与模块故障流程处理。

这些检查没有替代高云时序收敛、3.3V GPIO/上拉核对、真实MPR地址确认、装配阈值校准、功放噪声测试和示波器/逻辑分析仪延迟测量。未宣称已经达到赛题≤10ms/≤5ms实物延迟。
