## 3. 清点规则与限制

开发源码扩展名包括Verilog/SystemVerilog、Python、JS/CJS、Java、C/C++、Arduino、PowerShell/CMD、Tcl/DO、HTML/CSS和Gradle。`docs/`、`verification/`、`releases/`里的同类文件另外归档，避免把旧源副本和工具生成报告混算成当前开发代码。

`.gprj`、`.cst`、`.sdc`、`.hex`、权限XML、JSON数据和原生CAD不归入520项程序代码，但作为构建/运行或硬件输入保留索引。生成HTML仅按文件性质说明，不能按扩展名就当作自研网页。

静态解析跳过注释、字符串，识别已知模块名、可选参数括号及实例。它不展开预处理、generate参数或厂商原语，不是Verilog编译器。因此59模块/53文件仅帮助读代码，不能代替综合后网表，也不能推导振荡器计分数量。

逐文件用途是职责级解释，重点核对实际主链路，不代表对每一行代码重新做了安全审计或对全部历史功能重新验收。

## 4. 整理中发现并处理的问题

1. **中文文件名被Git转义。**最初用文本行读取树路径，会把中文名当成带引号的转义字符串。改用`ls-tree -z`和UTF-8解码；同时用`cat-file --batch`读取提交原始内容，避免换行/本地未提交文件混入。
2. **根README的“当前”指向旧分支。**新增清晰的当前版本入口，保留日期历史，不改写旧报告的原始结论。
3. **列入工程不等于真正使用。**完整GPRJ含独立测试与旧接口模块；静态关系与实际参数裁剪分开说明，尤其内部旧固定延迟在完整工程被旁路。
4. **源码GPRJ与发布快照GAO开关不同。**记录该转换并指向配套交付源码，避免以开启GAO的构建资源冒充已验证发布结果。
5. **旧快照也有源码后缀。**另列151项，不遗漏UART观察版、桥修复前后、宿主替身和ModelSim运行脚本，不把它们混成最新主源。
6. **部分已有结果容易被夸大。**区分38个选定用例与所有项目测试、仿真与实物、64逻辑声部与512分量状态、Goertzel显示与FFT验证、数字接口延迟与触摸到喇叭总延迟。

## 5. 复现清点和索引

在`TangMega60K_Synth`根目录，安装Python 3.11+和Git即可；不需要安装硬件驱动或连接板卡。

```powershell
python scripts/catalog-submission-sources.py --revision 603a417 --output docs/作品文档准备_20261026
python scripts/render-source-guide.py --directory docs/作品文档准备_20261026
```

如果改为另一个提交，应先审阅差异、更新人工用途JSON和版本文字，再渲染。Git归档ZIP中没有Git数据库时，可直接阅读已提供JSON/Markdown并运行渲染器；需要重做冻结提交清点时，使用正常克隆的Git仓库。
