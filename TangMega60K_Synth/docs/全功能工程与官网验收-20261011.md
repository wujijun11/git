## 操作与数据

- KEY0：内置曲谱自动演奏/停止。KEY1：脱机LED曲谱指引/停止（指引本身不自动发声）。两种模式切换先释放曲谱声部。KEY2：整机复位静音。
- 触摸默认MIDI60～84；源25～49。曲谱源0～24。手机源63，允许多个不同音高并发。按住时修改映射，释放仍使用原音高。
- 手机通信一次一条请求，ACK+CRC，最近一条相同事务重试不重复执行。三秒无有效通信或UART溢出时释放手机音符，保留物理键和曲谱声部。
- 手机“64声部现场测试”发送64个不同音高并读回活跃数；模拟模式只验证协议，不发声。紧急静音清掉上游旧事件，按住的触摸键必须松开再按，新手机命令排队保留；全局静音背压测试已通过。
- 记录的是演奏事件。所有记录可回传；板内录制回放支持物理键源25～49，含手机源63的记录可导出，但板内回放返回参数错误。
- 曲谱与录制存片内RAM，断电丢失用户数据。内置曲谱无需手机或蓝牙可用。
- 录音只保留音符、力度、音色和事件时间，不记录弯音/颤音参数或音效切换；回放不能完整重现这些演奏表情。
- 手机增益、弯音、颤音滑块拖动中连续发送，最多25次/秒；保留一条在途请求和一份最新待发快照，慢ACK不会堆积拖动历史。只更新实际拖动的参数，音量/颤音不覆盖实体滑条弯音。断线取消待发快照、旧会话上传与录音回传；失焦释放手机持键。该速率是控制包节流，不是物理演奏延迟测量结果。
- 在线曲谱目前接受HTTPS JSON和本地JSON，没有内置在线曲库或标准MIDI导入。这两项属于使用便利性增强，并非官网基础条款明确要求的格式。

## 实物连接

新约束依据[官方60K引脚表](https://dl.sipeed.com/fileList/TANG/Mega_138K_60K/08_Misc/tang_mega_60K_pins.cst)及[31004 Rev1.4底板原理图](https://dl.sipeed.com/fileList/TANG/Mega_138K_60K/02_Schematic/DOCK/Tang_Mega_NEO_Dock-60K_31004_Schematics.pdf)。用户早前照片存在31005字样；新J13连接在上板前应核对手中底板版本与导通，不能用外观猜测孔位。DAC已经验证的PMOD1连接保持原定义。

| 功能 | FPGA球位 | 官方J13针位/接口 |
| --- | --- | --- |
| 第1块 MPR（RTL索引0）SCL / SDA | E14 / E13 | J13-1 / 2 |
| 第2块 MPR（RTL索引1）SCL / SDA | C15 / C14 | J13-3 / 4 |
| 第3块 MPR（RTL索引2）SCL / SDA | B13 / C13 | J13-5 / 6 |
| FPGA UART RX / TX | A14 / A13 | J13-7 / 8（接BLE的TX / RX） |
| MPR IRQ0 / IRQ1 / IRQ2 | B16 / B15 / A16 | J13-9 / 10 / 13 |
| LED数据 | A15 | J13-14，先经3.3→5V电平转换 |
| DAC BCLK / LRCLK / DATA | Y21 / AB21 / AA20 | PMOD1 J8-11 / 9 / 7 |
| HDMI | J14/H14、J15/H15、K17/J17、G15/G16 | 底板HDMI；使能K13 |

MPR三个模块各自地址0x5A，分别接独立总线，使用3.3V供电与3.3V上拉。25键按8/8/9分组；滑条接第1块MPR（RTL索引0）的ELE8～11，这块还接琴键J1的ELE0～7，启用12通道。其余两块分别启用8/9通道。J13-11是5V，不可据此给MPR的3.3V脚供电。

新工程构建脚本将VCCX设置为1.8V，依据[Sipeed官方60K HDMI例程](https://github.com/sipeed/TangMega-60K-example/tree/main/cam_dvi)的硬件说明。这是工具的电压配置，不是要求用户改板上的供电。HDMI使用TLVDS输出，125MHz寄存器每拍移出两位，由ODDR形成250Mbit/s串行通道。复位只控制普通逻辑寄存器，避免OSER10跨高速I/O时钟的复位恢复路径；像素标记、符号数据、移位和ODDR输入仍由STA检查，没有对它们设置假路径。原厂模型已验证128个连续变化像素的通道对齐及PLL重启恢复。

用户已确认3块MPR121和功放5V电源买齐。还需25灯WS2812灯条或灯板、74AHCT125等适合单向3.3V输入的5V电平转换，以及ESP32-C3蓝牙板；灯条独立电源、连接件和线缆缺少才补。PCB琴键没有集成指引灯。蓝牙桥只传控制事件，不参与合成；推荐ESP32-C3-Zero-M已焊排针版，实际GPIO6/7和电源仍按模块原理图核对。已有PCM5102A/功放/喇叭继续使用。HDMI需线缆与支持640×480时序的显示器。
