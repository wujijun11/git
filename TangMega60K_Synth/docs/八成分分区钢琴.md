# 八成分分区钢琴（2026-09-23）

本页记录队员A的音源交付与原始验证结果。合并后的主工程采用八成分加法合成，
音色 2 使用四个参考音区；可选 FM 仍为音色 3。主工程原有 I2S 启动预备修复
保留，板级现有位流未因此自动更新。
64 个逻辑声部、原 ADSR 门控/松键/重触发、力度曲线、三维表情、混音增益、
24 位有符号立体声 PCM 和公共 V2 端口保持兼容。所有声音逐样本由 HDL 生成。

## 听感改动

第一版只拟合 A4v8，所有键直接变调。新模型用获得 CC BY 3.0 授权的
Salamander Grand Piano v3 / Alexander Holm 的四个 v12 单音作离线参考：

| MIDI 范围 | 参考 | 八个选定成分阶次 |
| --- | --- | --- |
| 0–64（目标区内 C4–E4） | C4v12 | 1、2、3、4、5、7、10、13 |
| 65–70（F4–A♯4） | A4v12 | 1–8 |
| 71–77（B4–F5） | C5v12 | 1–8 |
| 78–127（目标区内 F♯5–C6） | C6v12 | 1–8 |

按各参考音提取频率偏离整数倍的程度、左右声道幅度、相位和衰减轨迹；
移除录音开头的静默，使起音从生成包络开始。低音区选取更明显的高阶成分。
保留真实参考中的缓慢幅相变化；没有添加额外 FM 算子、录制的音头或噪声。
参考音的少量调律偏差仍可能体现在基频中，实测数字频率见 validation.json。

本轮参数每成分最多 32 条记录（含零尾音哨兵），最末段平滑归零。
参数拟合是稀疏幅度/相位控制，正弦表只有数学函数的一个周期。
原录音、残差信号、长 PCM 波形及录制脉冲响应均不存入音源 ROM。

## 资源与调度

两条共享流水线保持不变，每条依次计算四个成分。原每条 512×260 位的
参数 ROM 从“4 成分×128 段”改为“4 成分×4 音区×32 段”，总位数不变。
195 位声部成分状态也不加宽：原 7 位段指针高两位保存音区，低五位保存段号。
频率比率小表从 8×27 位变成 32×27 位。

音区只在 age=0 时按未弯音的 base_ftw 选择。播放中、滑音、颤音和基频更新
不会改该声部已锁存的音区；重新起音时选择新音区。两条线结果延迟仍为
10 个时钟，主引擎没有新增逐声部状态。

2026-09-23 已运行 ModelSim 八成分 4/64 声部回归：帧内计算仍为 69/969
时钟。969 的统计范围是 engine_sample_begin 到 FX_SEND，**不包含之后的
效果器输出等待、PCM 反压以及帧间命令处理**；完整期限应以 I2S 集成测试确认。

Gowin 1.9.12 综合相同 audio_system_v2_fm 顶层（保留 FM、开启延迟）：

| 项目 | 本轮前 | 本轮后 |
| --- | ---: | ---: |
| 逻辑单元（LUT+ALU） | 5392 | 5484 |
| 寄存器 | 3999 | 4033 |
| BSRAM | 70/118 | 70/118 |
| MULTALU27X18 原语 | 6 | 6 |
| MULT27X36 原语 | 11 | 11 |

新增 92 个逻辑单元和 34 个寄存器；片上 RAM 块数及乘法原语数未增加。
复合乘法原语不能直接按一个等于一个 18×18 DSP 计数。
综合出现原有的两条 HEX 文本 28 位与 27 位 ROM 宽度提示，所有数值均经
生成器检查小于 2^27，最高文本位为零；另有 Gowin 缓存 sh.log 打开提示。
综合完成不代表布局布线时序通过。正式 PLL、引脚和 SDC 仍由队长集成。

## 文件与接入

队长仍通过 V2 event_* 发送 timbre=2。音色 0 正弦、1 风琴、启用 FM 时的
3 FM 不变；普通 audio_system_v2 默认不启用 FM，audio_system_v2_fm 启用。

需要一起更新：

- rtl/audio/polar_lane.v：四音区寻址，新增私有 base_ftw 输入。
- rtl/audio/voice_engine.v：将声部未弯音频率接入该私有输入。
- rtl/audio/rom/polar_lane0.hex、polar_lane1.hex、polar_ratios.hex。
- assets/audio/piano_eight_profiles.json：可重建 ROM 的参数及来源记录。

私有 base_ftw 输入不是对队长公共 V2 接口的扩展。不添加板卡引脚，
不启用 PT8211，不改变 I2S 标准 Philips、24 位数据/32 位声道槽约定。
旧 RTL、ROM 已保存在交付目录 before 中，旧音频另用相同测试台重新仿真。

## 复现

在工程目录执行；常规验证只需 Python + numpy，**不需要录音文件或联网**：

```powershell
./scripts/test-eight-piano.ps1 -PythonExe python -OutputDir sim/eight_results
./scripts/synth-eight-piano.ps1 -OutputDir sim/eight_synthesis
```

参数 ROM 也可单独重建：

```powershell
python scripts/piano_model/refine_eight.py --model assets/audio/piano_eight_profiles.json --rom rtl/audio/rom
```

若要重新从参考录音拟合，额外安装 soundfile，并执行：

```powershell
python scripts/piano_model/refine_eight.py --references reference_wav --download --model assets/audio/piano_eight_profiles.json --rom rtl/audio/rom
```

--download 只获取固定提交下的四个已注明授权的参考单音，离线拟合后产生参数。
不要用历史 convert_polar.py 将单音区 ROM 覆盖到当前四音区 RTL。

## 验证与范围

- tb_eight_regions：四音区数字样本与独立定点模型逐样本核对；A4 完整自然
  衰减；64 份独立状态；音区锁存；停顿和复位；每条线 10 时钟交付。
- tb_audio_engine：分别运行 4/64 声部八成分回归，覆盖中性、表情快照、
  满载、快速重触发、提前松键、PCM/done 反压与尾音回收。
- tb_audio_i2s：64 声部钢琴、延迟开启、表情更新，逐位核对 Philips I2S。
- tb_fm_keyboard 参数 TIMBRE=2：通过 V2 分配器逐键生成 C4–C6 的 25 个
  音，每音按住 1 秒、释放 0.2 秒。该试听使用 4 声部配置、每次一个音，
  不把逐键试听叫作 25/64 音并发。独立 64 声部压力测试另行运行。
- FM 原有 4/64 声部回归继续运行，确认其独立可选路径仍可用。

上述测试本轮均实际运行通过。四音区合计 864,100 帧立体声成分输出与独立
定点模型逐样本一致；25 键共 1,440,000 帧原始 PCM 未触及 24 位削波值，
25 次释放均回收。I2S 实际对拍 12,062 帧，稳定阶段新增欠载为 0；
队员A原交付分支的启动阶段有 1 次欠载；主工程合并时保留了此前已验证的
I2S 启动预备修复，合并后的欠载情况应以主工程复测结果为准。
FM 4/64 声部回归通过，帧内计算为 53/713 时钟。

以 2048 点滑动频谱、逐声道 RMS 归一化（消除既有声像增益影响）比较
前 1 秒与拟合用参考录音的幅度谱，相对误差如下。这里不是听感评分：

仍有局限：八成分不能完整重建琴槌宽带噪声、所有弦模态和真实踏板共鸣；
四音区边界可能听到音色变化；力度目前主要控制音量，未实现多力度采样式
参数插值。C4–C6 以外虽仍可变调，不作为本轮拟真音域验证结论。
参考频谱差异是对拟合用录音的比较，不是独立听感评分。
布局布线、DAC 听感、模拟频谱、整机延迟及现场达标仍待实测。
