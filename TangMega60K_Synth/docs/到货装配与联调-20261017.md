# 到货装配与联调

2026-10-17用户确认材料已到齐。此记录仅确认到货，不代表已焊接、下载、通电或通过实物测试。整机先分项接线验收，再组合。

## 当前第一步：断电准备

1. 从相同琴键PCB中取一块使用；其余备用。滑条取一块。
2. 琴键J1/J2/J3分别焊1×8、1×8、1×9公排针，滑条J4焊1×4，间距2.54mm。排针从背面引出，正面琴键保持平整；先固定一根端针，确认方向后焊其余针。
3. 以方形焊盘识别pin1。面对正面时的左右关系在背面会反转，不能凭背面从左至右顺接。
4. 尚未接模块时检查相邻针无连锡，各电极线到对应键区导通。使用绝缘支柱，避免背面焊点触碰金属或桌面导电物。

完整逐键表见[琴键接线](../hardware/touch25/assembly_wiring_zh.md)，背面排针和线束见[装配示意](../hardware/touch25/harness_assembly_zh.md)。触摸电极表面的阻焊不需要刮除。

## 电极与模块映射

以下是排针到MPR电极的信号连接，不是电源线：

| PCB接口 | 对应MPR121 | 对应通道 |
| --- | --- | --- |
| 琴键J1 pin1～8 | 第1块，RTL索引0 | ELE0～7 |
| 琴键J2 pin1～8 | 第2块，RTL索引1 | ELE0～7 |
| 琴键J3 pin1～9 | 第3块，RTL索引2 | ELE0～8 |
| 滑条J4 pin1～4 | 第1块，RTL索引0 | ELE8～11 |

琴键和滑条PCB没有要接5V/3.3V的供电针；上表接口全部是敏感电极，不能接FPGA GPIO。模块按ELE丝印逐针接，线尽量短并固定，避开DAC时钟和功放/喇叭线。

## 接入FPGA前核对

之前照片可见底板31005编号。现已按60K核心BTB和31005底板BTB核对J13全部12个信号映射，完整孔号、电源分配及蓝牙/LED接法见[整机连线方案](整机连线方案-20261017.md)。现场仍需认准J13/J9和pin1方向，核对供电与导通后接入；不能凭照片左右关系数孔。

MPR需要确认模块的3.3V供电、GND、SCL、SDA、IRQ及上拉接法。三块分别使用独立I²C总线，当前代码均用地址0x5A；不能把三组SCL/SDA并成一条总线。模块具体VIN/3V3接法按实物确认。不要用1.5V板载按键接口连接外设。

电平转换器也先确认实物型号：裸DIP14芯片与已焊排针模块接法不同；带HV/LV的通用双向板不能仅凭“3.3V转5V”字样认作74AHCT125。

## 分项验收顺序

1. **第一组8键**：核实底板接口和供电后，只接第1块MPR及琴键J1。保持原来已验证的DAC/功放接线。下载当前受验主工程，检查C4～G4八键、按住、松手和多键；未连接的第2/3块离线是预期状态。
2. **全部25键**：第1组通过后，逐块加第2、第3组；检查C4～C6连续25个半音、跨模块和弦与松手释放。
3. **滑条**：接第1块ELE8～11，按住一个琴键检查左/中/右音高变化，松开回中。最终贴膜、支架和线束固定后再做阈值/端点校准。
4. **25灯板**：确认DIN、5V、GND的实际线序。独立5V供电并与FPGA共地；FPGA数据经5V供电的74AHCT125，再串330Ω进入DIN。AHCT近端0.1µF去耦，灯板入口500～1000µF电解电容按正负极并接。不要将3P插头直接套到三根相邻GPIO上。灯序用[校准曲谱](../hardware/led25/calibration-25.json)逐灯核对。
5. **蓝牙**：先给C3用USB供电和烧录，之后将GPIO7/TX接FPGA UART RX、GPIO6/RX接FPGA UART TX并共地，逻辑均3.3V。不是C3上标RX/TX的GPIO20/21。安装APK，连接Tang-Synth-C3，确认状态读回后再试手机音符与全部停止。
6. **整机**：检查各输入、音色、表情、音效、LED引导、手机断连释放和HDMI（有显示设备时）。延迟、功放干扰与音量以实测记录，不用仿真结论代替。

每次改线先断电；首次试听将功放音量调低。不要把5V引入FPGA GPIO；C3使用USB时不随意并接另一路5V电源。
