## 串口接线

| ESP32-C3 | FPGA NEO Dock |
| --- | --- |
| GPIO7 / UART TX | J13-7 / A14 / UART RX |
| GPIO6 / UART RX | J13-8 / A13 / UART TX |
| GND | J13-12 / GND |

串口为 115200、8N1、3.3V。C3 的 USB 串口当前只供日志使用；FPGA DEBUG USB 用于下载与片内分析。协议连接需返回同序号 ACK 并完成状态同步，软件才显示 FPGA 已连接。

## 构建与诊断

1. 在工程目录用 GOWIN 运行 `scripts/build-contest-full.tcl`，或使用 `scripts/build-contest-isolated.py` 生成独立完整快照；工具与 Python 依赖按各脚本说明配置。
2. C3 使用 `scripts/build-ble-bridge.ps1`，要求 Arduino-ESP32 3.3.5、微雪 ESP32-C3-Zero 目标和仓库中的 `firmware/libraries/BridgeBLE`，不要退回全局未修补的 BLE 库。
3. Windows 软件使用 `desktop/build.ps1`；移动端源码仍在 `mobile/`，本轮没有重新宣称发布新的 APK。
4. [UART 被动观测说明](../verification/uart-live-debug-20261023/README-observation.md)附完整源码副本、等价仿真、GAO 解码器及实机基线。`observation-source/` 与生产主源分开；该副本没有生成诊断 ACK，也没有改变外部引脚或琴键功能。

一次 READBACK 正常应收到 16 字节请求、接受 1 条命令，再发出 ACK 加遥测共 32 字节。当前只有发送前的空闲基线，不能据此判定物理串口已经导通。若重启或重新下载，必须重新采集基线。
