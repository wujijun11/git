# 24位标准I2S恢复与PT8211模式移除

日期：2026-09-19。按用户最终要求，当前工程只保留24位标准Philips I2S输出。

## 输出规格

- 左右声道各24位有符号PCM，每声道32个BCLK；每帧64个BCLK。
- WS低为左声道，高为右声道；WS翻转后延迟一个BCLK发送MSB。
- 数据在BCLK下降沿改变，接收端在上升沿采样；空余位置补零。
- 默认系统时钟49.152MHz，BCLK_HALF_DIV=8，BCLK=3.072MHz，采样率48kHz。
- 64个独立合成声部混合为左右两个输出声道，不是64路物理音频接口。

## 改动范围

`rtl/i2s_tx.v`移除PT8211发送分支及16位截取；`rtl/captain_system_top_v2.v`和`rtl/audio/audio_system_v2.v`移除PT8211_MODE参数及传递。干声和延迟顶层使用相同I2S格式。

删除专用文件：`sim/tb_pt8211_tx.sv`、`sim/tb_audio_pt8211.sv`、`sim/run_pt8211.do`、`scripts/test-pt8211.ps1`、`sim/pt8211_unit.vvp`。清除公共测试脚本中的PT8211入口；GUI波形脚本运行`tb_audio_i2s`。

事件、表情、PCM接口保持不变。除上述三个RTL文件外，其余22个RTL及ROM文件与移除前验证副本逐字节一致，核查清单见本次结果目录的`change_scope.json`。历史适配文档及已有仿真结果保留用于追溯，历史PT8211脚本与模式说明不再适用于当前源码。

## 下一步使用

完整音频打开`AudioEngine_V2.gprj`，干声顶层`audio_system_v2`，50ms延迟效果顶层`audio_system_v2_delay`。ModelSim在项目根目录执行：

```tcl
do sim/waves_audio_v2.do
```

当前接口需要支持24位标准I2S的DAC；不能将它当作PT8211的LSBJ输入直接连接。实际板级顶层、音频PLL、引脚CST、时序SDC及DAC接线仍需完成并上板验证。本次修改不代表物理底板已可直接烧录发声。
