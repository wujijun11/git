# 推荐曲目与刷新

## 使用方法

电脑进入“曲谱”页，手机滑到“找一首，弹起来”，会自动加载“看看这些”推荐区。每批最多6首，从Mutopia真实曲库中筛选有MIDI的键盘曲谱，优先钢琴独奏，显示作者、授权和推荐原因。

- **换一批**：换一组查询页；有缓存时复用缓存，不必每次等待联网。
- **刷新曲库**：保留当前批次，绕过24小时缓存重新联网。刷新后内容可能相同，表示这一页没有变化，不会假装产生新歌。
- **查看并导入**：打开原有音轨和片段编辑器，选择范围、分析容量、确认转换提示，再导入当前曲谱。之后仍需明确点击上传。

搜索和推荐区分别展示，推荐刷新不会覆盖正在编辑的MIDI、音轨和时间范围。失败时原推荐卡片保留；如果有旧搜索缓存，会显示“联网失败，显示旧缓存”。首次无缓存且断网时明确提示，可重试、手动搜索或导入本地MIDI。

这不是热门歌曲榜或个性化推荐，没有上传演奏记录，也不保证搜到流行歌。推荐表示值得继续查看，不表示整首已经满足25键、1024条事件或演奏难度。仍需选择旋律轨/片段并分析，超限处理保持原规则，不偷偷截曲。

曲目来自[Mutopia公开曲库](https://www.mutopiaproject.org/)，逐曲授权信息保留；使用条件见[官方授权说明](https://www.mutopiaproject.org/legal.html)。只下载MIDI演奏数据，最终声音继续由FPGA实时合成。推荐不会直接占用FPGA RAM，只有用户明确上传事件后才写入原曲谱RAM。

## 实现分工

| 模块 | 职责 |
| --- | --- |
| `desktop/score_library/recommendations.py` | 推荐批次、MIDI/键盘筛选、独奏优先、去重、空页回退 |
| `desktop/score_library/mutopia.py` | 真实搜索及24小时缓存，强制刷新、网络失败旧缓存、并发安全临时文件 |
| `desktop/score_library/service.py` | 为推荐结果生成安全下载令牌，与原文件预览/转换复用 |
| `desktop/native_host.py` | 推荐API入口，不直接操作音符或上传曲谱 |
| `desktop/web/score-library.js/css` | 电脑推荐卡片、换批/刷新、局部加载状态、复用原编辑器 |
| `mobile/android/.../MusicRecommendations.java` | 手机推荐筛选与原因，独立于网络和蓝牙 |
| `MusicCatalog.java` | 手机推荐请求、曲库缓存及强制联网刷新 |
| `mobile/web/music/library.js` | 推荐请求通过原生桥通信，不产生BLE控制命令 |
| `mobile/web/music/panel.js` | 手机推荐区、保留编辑内容、失败恢复及导入 |

当前批次按20个钢琴搜索页轮换，结果不足或曲库分页缩短时回首页。推荐批次可能在循环后重复，不宣称无限新曲。每次最多两个曲库搜索请求；单个推荐操作期间按钮禁用，避免连点并发。电脑保留最多128个曲目下载令牌、32个已解析文件，手机原解析文件上限仍为32。

## 实际验证

6项Python测试通过：筛选、独奏优先、去重、批次换页、刷新参数、空页回退、缓存绕过和联网失败保留、安全下载令牌。Android实际Java推荐模块已编译/运行筛选测试，保留原10条真实搜索HTML核对及URL/大小限制测试。

独立浏览器同时验证电脑和390像素手机界面：自动加载6首、换批、强制刷新标志、离线提示、失败保留卡片、正在编辑片段保留、推荐打开原编辑器、手动搜索仍工作、标题作为文字显示且不执行、无横向溢出、没有连接硬件或发送控制命令。

实际联网检查得到两批不同的推荐，各6首；确认普通读取命中缓存、强制刷新联网，并成功下载/解析第一批的一份MIDI。原曲库、1024条上传、模式同步、自定义电脑快捷键和手机异步上传回归通过。

Windows新版实际打包并检查推荐模块；Android1.6实际编译、lint和开发签名校验通过。没有替用户启动新软件、安装手机或连接/刷写板卡。这次只改客户端，FPGA `.fs` 和C3固件不需更换。

```powershell

./scripts/test-music-library.ps1 -IncludeUI

# 以下命令实际联网到官方曲库：

```

交付目录 `delivery-recommendations` 包含Windows程序、Android1.6、完整源码包和校验清单。旧 `delivery-keyboard-shortcuts` 与 `delivery-ble-latency` 保留，推荐新版继续包含自定义按键和低延迟连接改动。
