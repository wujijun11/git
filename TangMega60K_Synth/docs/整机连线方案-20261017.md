# 25键电子乐器整机连线方案

本方案对应当前 `full/ContestFull.gprj`、Tang Mega 60K核心、用户照片中的31005底板、3块HW-1017/MPR121、四电极滑条、微雪ESP32-C3-Zero/Zero-M及25灯WS2812B。2026-10-17已核对60K核心BTB与31005底板BTB/外部接口的连接关系；这不是把138K球位直接套到60K。

孔号属于连接器编号，**不是照片中的左右位置**。实物先认J13/J9丝印和1号脚；接线时全部断电。底板供电、导通和外设功能尚未现场验收。若只接蓝牙，先看第一节。

用户6张实物照片的[箭头标注图](../hardware/assembly_photos/20261017/README.md)已另行整理：包括MPR、琴键J2及PMOD0供电位置。照片中的长排孔可认定为J14，J13及其pin1尚未在照片中清楚显示，因此蓝牙具体插孔未在实物图上猜测标注。

## 1. 蓝牙：3根杜邦线＋USB供电

适用固件已将UART重映射到GPIO6/7。

| 微雪C3端 | FPGA底板端 | 方向 |
| --- | --- | --- |
| GPIO7 | **J13第7脚** | C3 TX → FPGA RX |
| GPIO6 | **J13第8脚** | C3 RX ← FPGA TX |
| GND | **J13第12脚** | 公共地 |
| USB-C | 支持数据传输的USB线接电脑 | 首次烧录与供电 |

两边都是公排针时用母对母杜邦线；FPGA端若是母座，用公对母。UART是3.3V逻辑，这一路直接连接，不经过74AHCT125。C3使用USB供电时，先不另接它的5V/3V3供电脚。

认GPIO数字6、7，不认C3板上TX/RX字样：该板丝印TX/RX对应GPIO21/20，并非本工程使用的串口脚。依据[微雪说明](https://docs.waveshare.net/ESP32-C3-Zero/)，先确认实物为Zero/Zero-M；其他C3型号需要重新核对引脚。

必须先烧录项目蓝牙桥固件，才能在APK中连接`Tang-Synth-C3`。首次烧录可按住BOOT后接USB，或按住BOOT、按下并松开RESET，再松开BOOT；烧录成功后按RESET运行。不要把电脑已有的“蓝牙链接上的标准串行COM5”当作C3的USB设备。

推荐先在电脑完成C3烧录，断电后接上表3根线，再安装[APK 1.2](../mobile/android/output/TangSynthRemote-debug.apk)。连接后检查FPGA握手/状态读回，再测试手机音符和全部停止；C3彩灯变绿只证明BLE连接，不证明FPGA已响应。

## 2. J13信号总表

以下映射均已沿60K核心30354的C2399 → 31005底板J1 → J13核对，详见[接口映射核对](31005接口映射核对-20261017.md)。

| J13脚号 | 外设连接 | 当前FPGA球位 |
| ---: | --- | --- |
| 1 | MPR① SCL | E14 |
| 2 | MPR① SDA | E13 |
| 3 | MPR② SCL | C15 |
| 4 | MPR② SDA | C14 |
| 5 | MPR③ SCL | B13 |
| 6 | MPR③ SDA | C13 |
| 7 | C3 GPIO7（C3 TX） | A14，FPGA RX |
| 8 | C3 GPIO6（C3 RX） | A13，FPGA TX |
| 9 | MPR① IRQ | B16 |
| 10 | MPR② IRQ | B15 |
| 11 | 底板5V电源；本方案首次接线留空 | — |
| 12 | 公共GND | — |
| 13 | MPR③ IRQ | A16 |
| 14 | 74AHCT125输入A，去往LED | A15 |

J13是SDRAM0的2×20接口，原理图标注靠近PCIe连接器。它与另一组J14不能混淆，也不能同时插SDRAM扩展板。

编号规则示意如下，**这不是实物朝向图**：找到1/2这对后，同一排依次1、3、5……，另一排2、4、6……。不要把第7脚数成一排中的第7个孔。

```text
奇数排              偶数排
1   MPR① SCL        2   MPR① SDA
3   MPR② SCL        4   MPR② SDA
5   MPR③ SCL        6   MPR③ SDA
7   接C3 GPIO7      8   接C3 GPIO6
9   MPR① IRQ       10   MPR② IRQ
11  5V（留空）     12   GND
13  MPR③ IRQ       14   LED→转换器输入
……                 ……
```

## 3. 琴键／滑条到MPR121

这部分共29根电极线，使用焊牢的排针与母对母杜邦线。每块模块按0～11丝印辨认，电极0不是GND。

| 面板接口 | 对应模块 | 模块电极 |
| --- | --- | --- |
| 琴键J1 pin1～8 | MPR① | ELE0～7，逐针对应 |
| 琴键J2 pin1～8 | MPR② | ELE0～7，逐针对应 |
| 琴键J3 pin1～9 | MPR③ | ELE0～8，逐针对应 |
| 滑条J4 pin1～4 | MPR① | ELE8～11，逐针对应 |

例如J1的1→ELE0、2→ELE1……8→ELE7。琴键正面的方形焊盘是pin1；背面装线左右会反转。琴键/滑条接口全部为电极，不能接电源或FPGA GPIO。电极线尽量短并固定，避开I²S和功放输出线。

三块MPR各自底部的SCL/SDA/IRQ按第二节连接；三组总线相互独立，不能把三块SCL/SDA并在一起。

| 三块MPR各自的端子 | 连接 |
| --- | --- |
| 3.3V | 从底板PMOD0 **J9第1脚或第2脚**引出3.3V，再分配给3块模块 |
| GND | 公共GND，可从**J9第3/4脚**或J13第12脚引出分配 |
| ADD | 各自接GND，选择地址0x5A |
| SCL/SDA/IRQ | 各自独立接第二节表中对应脚 |

使用面包板电源排或可靠分线端子分配3.3V/GND，不能在一个排针上硬套多个母头。先核对J9编号并测得3.3V；J9是PMOD0，现有DAC使用的J8是PMOD1。

**J13第11脚是5V，不是3.3V；J13默认没有可直接取用的3.3V脚。** 第29/30脚为EXIO信号，默认电阻装配连接DQM，不能当3.3V/GND用。MPR地址连接依据[NXP MPR121手册](https://www.nxp.com/docs/en/data-sheet/MPR121.pdf)。

## 4. 25灯WS2812B与74AHCT125

数据链：**J13第14脚 → 74AHCT125输入A → 输出Y → 330Ω电阻 → 灯板DIN**。330Ω放在靠近灯板DIN的位置。

| 端点 | 接法 |
| --- | --- |
| 灯板5V | 外接稳压5V电源正极，用合适供电线 |
| 灯板GND | 外接电源负极，并与FPGA公共GND相连 |
| 灯板DIN | 来自74AHCT125输出Y，经过330Ω |
| 74AHCT125 VCC | 同一外接5V电源正极 |
| 74AHCT125 GND | 公共GND |
| 74AHCT125所用通道的低有效OE | 接GND使能；模块内部已接地则按模块电路确认 |

USB免焊公头可以从5V USB电源引出5V/GND；端子按VBUS/5V与GND丝印辨认，其余D+/D−/屏蔽端本次不用。外接5V正极只供灯板和转换器，不再随意接入已用USB供电的FPGA或C3电源脚。所有设备需要共地。

0.1µF（104）瓷片电容并接AHCT的VCC/GND并靠近芯片。1000µF/10V电解电容并接灯板电源入口，正极接5V，负极接GND；带负号条纹的一侧为负极。灯板3P线序按实物DIN/5V/GND确认，不整只插到FPGA相邻三针。

### 如果买的是裸SN74AHCT125N（DIP14）

先放在面包板中缝两侧，或焊在合适转接板上。以下只适用于14脚N封装，模块版不能照物理脚号套用。看芯片顶面，缺口朝上时左上为1号脚，沿左侧向下1～7，右侧由下向上8～14。

| 芯片脚 | 接法 |
| --- | --- |
| 14 VCC | 外接5V |
| 7 GND | 公共GND |
| 1，1OE | GND，使能第一通道 |
| 2，1A | FPGA J13-14 |
| 3，1Y | 330Ω，再到灯板DIN |
| 4、10、13，其他OE | 5V，关闭未用通道 |
| 5、9、12，其他A | GND，固定未用输入 |
| 6、8、11，其他Y | 留空 |

14/7脚近端并0.1µF去耦。引脚、低有效OE及未用输入处理依据[TI SN74AHCT125手册](https://www.ti.com/lit/ds/symlink/sn74ahct125.pdf)。这是5V供电、可接收3.3V逻辑输入的AHCT缓冲器；通用BSS138双向转换板不按此表接。

## 5. 原音频链路

既有PCM5102A → 功放 → 喇叭链已有播放/停止/重播反馈，本次增加外设时先保留其已确认接法。当前数字音频引脚仍为：

| FPGA PMOD1 | PCM5102A |
| --- | --- |
| J8-11，Y21 | BCLK/BCK |
| J8-9，AB21 | LRCLK/LCK/WS |
| J8-7，AA20 | DATA/DIN |
| J8-3/4，GND | DAC GND |

DAC模块VIN/3V3端的允许电压须按实物电路确认；本表不凭外观重新指定其电源电压。DAC模拟输出接功放输入，喇叭接功放输出，不接FPGA GPIO。

## 6. 装好后的顺序

1. 确认J13、J9及pin1，断电查线与短路；首次测电源时先不接外设信号，测J9 3.3V及外接5V后再断电接线。
2. 使用受验交付包的`fpga/ContestFull.fs`配置FPGA；烧录对应C3固件。文件生成并不表示已经下载。
3. 先验证MPR①八键，再加②③及滑条；上电校准时松开所有触摸区。
4. 验证LED方向与逐灯编号；25灯物理链序先用[校准曲谱](../hardware/led25/calibration-25.json)确认。
5. 在APK中连接C3并读回FPGA状态，再测手机琴键、音色、表情、全部停止与断线释放。首次试听将功放音量调低。

当前软件与位流见[受验交付包](../release/verified_20261016_213325_9a4e6267.zip)；构建/仿真范围见[本轮交付核验](../verification/optimization-20261015/README.md)。本方案是接线定义，不是现场通电、蓝牙或整机功能已经通过的声明。
