## 修改与功能保持

1. 触摸事件队列：入队和持键写使能只依赖已寄存的容量，不再经过下游 `ready→pop` 组合反馈。满时停留在当前扫描项，保留释放事件和原音高/音色；合法预约容量内无新增流水延迟。
2. 曲谱控制：动作、上传、提交分别判断；256行有效位用并行归约。提交后的有效位批量清零延后一拍，并立即屏蔽旧上传状态；下一拍新写入覆盖其自身位。对外命令和音频调度周期保持。
3. 音效：延迟/合唱与混响互斥，共享四个16位存储bank。完整48位立体声历史拆成3×16位，混响comb与allpass分区复用。保留24位输出、原历史长度、饱和、算法和握手周期。
4. 本地按键：忙状态单独输出，按键的ready不再通过包含曲谱提交验证的公共状态选择器。按键源抽成同文件中的真实子模块供专项验证；不增加命令流水级或响应延迟。

没有修改SDC/CST来放宽时钟、增加假路径或跳过恢复/移除检查。64声部、256行曲谱和1024行演奏事件记录容量保持；数学波形和模型参数ROM保持，不加入预录PCM/WAV播放。
