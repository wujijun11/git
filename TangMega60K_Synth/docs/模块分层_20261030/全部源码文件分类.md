# 全部源码文件分类

[返回总览](README.md)

共596个代码/脚本文件。列入此表仅表示已清点用途，不表示本轮运行过每个测试。

范围：当前Git跟踪文件与未忽略的新代码；包括自研代码、C3第三方BLE库、硬件CAD辅助脚本、独立小工程和测试。排除docs历史报告中的代码副本、verification运行副本、releases/delivery分发副本、tmp依赖和assets素材。ROM、约束、项目配置另在总览说明，不把它们当作可执行源码重复统计。
