## learning_stepper

定义：[rtl/performance/learning_stepper.v:4](https://github.com/wujijun11/git/blob/codex/sustain-20261030/TangMega60K_Synth/rtl/performance/learning_stepper.v#L4)

用途：学习模式判定器：等待松键、等待正确目标/和弦，按齐才前进；不限等待时间，本版不考核节奏。

时序/注意事项：row握手读取音符行，按目标聚合学习步骤；touch_ready是采集初始化条件。只有用户按齐目标才前进，可无限等待，不能用普通定时播放代替。

源码中本模块自己的边沿触发条件：`posedge clk`。子模块还可有自己的时序。

## performance_controller

定义：[rtl/performance/performance_controller.v:2](https://github.com/wujijun11/git/blob/codex/sustain-20261030/TangMega60K_Synth/rtl/performance/performance_controller.v#L2)

用途：曲谱/录制RAM、时间调度、播放、停止释放、指引与学习的业务核心；当前板上曲谱容量1024条事件，不是1024首歌，也不保存PCM。

时序/注意事项：command口提交曲谱业务；event口输出调度后的音符。record_valid只观察已经接受的演奏，不能反压。record_read_index经同步RAM返回record_read_valid/row_payload。板内容量由SCORE_CAPACITY/RECORD_CAPACITY决定。

源码中本模块自己的边沿触发条件：`posedge clk`。子模块还可有自己的时序。

### 编译参数（模块默认值）

下列默认值不是当前父实例一定采用的值；覆盖项见本节末尾。

| 参数 | 默认表达式 | 含义/单位 |
|---|---|---|
| `CLK_HZ` | `49152000` | 本模块工作时钟频率，单位Hz；用于换算计数周期，不创建新时钟。 |
| `SCORE_CAPACITY` | `1024` | 板内曲谱RAM容量，单位事件条数，不是歌曲数。 |
| `RECORD_CAPACITY` | `1024` | 板内演奏录制RAM容量，单位事件条数。 |
| `SCORE_SOURCE_BASE` | `0` | 普通曲谱按键来源编号基址。 |
| `RECORD_SOURCE_BASE` | `25` | 录制回放来源编号基址。 |
| `DIRECT_SCORE_ENABLE` | `0` | 功能/接口选择参数，通常0关闭、1开启；不是运行时按钮。 |
| `LEARNING_ENABLE` | `0` | 功能/接口选择参数，通常0关闭、1开启；不是运行时按钮。 |
| `DIRECT_SCORE_SOURCE` | `6'd62` | 直接MIDI音高曲谱的来源编号。 |
