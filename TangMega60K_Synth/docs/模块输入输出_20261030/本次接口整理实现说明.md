# 模块输入输出整理实现说明

日期：2026-10-30。分支：codex/sustain-20261030。对象：当前延音测试版7D2F。

## 整理结果

从90个RTL文件实际提取97个模块、1465个端口和122处已知模块命名实例。
每个模块按输入、输出、双向分别列出端口名、参数化位宽、默认位数、是否有符号、
中文含义、单位/范围、一处实际父级连接，以及所有父实例的参数覆盖。
连接索引另保留每处实例的完整命名连线，包括常量、未连接输出和源码中的条件分支。

本次未修改HDL、音色、ROM、公共V2接口或板卡约束，未重新生成位流，未下载到板上。
这是源码阅读资料，不是新增延音的上板验收报告。

## 工具分工

| 文件 | 职责 |
|---|---|
| scripts/document-module-interfaces.py | 清除注释但保留行号与字符串，提取module参数/ANSI端口，安全计算默认位宽，解析命名实例。 |
| scripts/module_docs/interface_meanings.py | 人工核对端口中文含义及模块同名端口特例。 |
| scripts/module_docs/interface_guides.py | 时序、握手、参数单位和范围说明。 |
| scripts/module_docs/render_interfaces.py | 生成分层端口表、连接索引、初学者说明和导航。 |

所有文件采用UTF-8。声明解析、人工语义和文档渲染分开，便于接口改变后逐项维护。
生成命令，在工程目录运行：

```powershell
python -B -X utf8 scripts/document-module-layers.py
python -B -X utf8 scripts/document-module-interfaces.py
```

先重建分层清单，是为了重新核对工作区文件SHA256；生成器不能用旧清单默许已变化的接口。

## 实际核对与边界

- 解析器小用例检查：连续同方向端口继承位宽/有符号属性、嵌套拼接和函数中的逗号、字符串、
  显式未连接端口、Verilog整数常量、$clog2及默认整数算术。
- 97个模块、122个父子实例关系与之前独立分层解析器统计一致。
- 每处命名连接的端口名均存在于目标module定义中，默认位宽全部成功计算。
- 1465个端口都有中文解释，参数也有单位/职责说明；没有将未解释项静默略去。
- 90个RTL文件SHA256与分层清单一致；后续发布保护核对又与实际已构建冻结输入逐字节比较。

当前工具服务于本工程使用的ANSI模块头和命名实例，不是完整SystemVerilog编译器。
它不展开generate条件、循环复制或SIM/综合互斥分支，不计算所有父参数覆盖后的实际展开网络，
不取代ModelSim/Gowin时序检查，也不统计厂商原语内部端口和测试台接口。

## 发现的问题与处理

| 问题 | 处理 |
|---|---|
| 最初解析器不支持output reg rgb_data=0 | 保留声明初值字段，加入端口名与初值分离；没有改RTL来迁就解析器。 |
| 同名valid不一定是相同协议 | 区分ready/valid流、单拍字节/提示事件、音频观察和流水线完成。 |
| 同名key_valid可代表触摸事件或板载业务动作 | 为local_action_arbiter写专用解释，避免把本地录放动作误当琴键NoteOn。 |
| 默认WIDTH=101与当前音源RAM不一致 | 明确当前voice_engine.u_state覆盖WIDTH=125，不用默认位宽指导实际接线。 |
| 参数LEFT_STEP/RIGHT_STEP容易被当作时钟周期 | 明确它们是测试三角波的32位相位步长，不是时间门限。 |
| 频率倍率的定点单位不能凭位宽猜测 | 对照pitch_expression的1倍初值1048576和voice_engine右移20，标明frame_ratio为Q3.20。 |
| 本地绝对C盘链接无法给队友使用 | 源码链接指向本独立GitHub分支，文档导航使用相对路径。 |

未重复运行音源仿真或综合：本轮只改文档工具，现有位流没有变化。
原延音34项ModelSim入口、21条客户端检查及Gowin报告属于之前实际执行的验证，
其原始证据仍在docs/reports/sustain-20261030；新增延音实物听感与长期稳定性保留待测。
