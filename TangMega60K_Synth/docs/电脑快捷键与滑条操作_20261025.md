# 电脑快捷键自定义与滑条速查

## 自定义电脑字母键

打开新版电脑程序 → 设置 → 自定义电脑快捷键 → 找到第几琴键并点“更改” → 按所需按键 → 保存并应用。更改只是草稿，保存后才成为实际演奏布局。

例如第1琴键默认由Z触发；把它改为A并保存后，A触发第1琴键，Z不再触发。第1琴键弹什么音仍由原“25键MIDI映射”决定，默认是C4（MIDI60）。自定义电脑字母键不会改实体触摸键、音高或蓝牙协议。

支持字母、主键盘数字、小键盘数字和常用标点；不能把Ctrl/Alt/Win组合键、功能键或Esc分配给音符。每个电脑键只能分配一次；冲突时先清除原绑定，或换一个未使用的键。按键绑定依据物理键位置event.code，改变大小写或开启大写锁定不会产生另一套绑定。

- “清除”：该琴键暂不使用电脑键触发，鼠标和实体琴键仍可使用。
- “恢复默认布局”：恢复默认草稿，再点保存生效。
- “取消修改”：放弃未保存草稿。
- Esc一直为全部停止；选快捷键时按Esc同时取消选择并全停。
- 在输入框编辑文字、输入法组字或使用Ctrl/Alt/Win快捷键时，不触发电脑琴键。

设置保存在本机 `%LOCALAPPDATA%\TangNeonStudio\preferences\keyboard-shortcuts.json`。打包程序每次启动的网页端口会变化，因此由独立原生偏好模块读写，不依赖浏览器来源缓存。设置文件损坏时提示并用默认布局，保留原文件；不会自动覆盖。浏览器演示没有原生API时，才使用该浏览器来源的localStorage。

开始选择/应用快捷键时，先释放电脑当前按住的音符，避免旧键释放不到新布局中的声部。正常弹奏的短音仍完整发送，不使用之前已撤销的短音取消策略。

## 滑条现在负责什么

当前滑条负责分区菜单，不再直接连续弯音。最左端按住约1秒，**松手后**进入总菜单。总菜单从左到右是音色、音区、录放、曲谱/指引；短触某区并松手进入对应页面。子页面四区执行下面的操作，再长按最左端后松手回总菜单。

| 子页面 | 左边第1区 | 第2区 | 第3区 | 右边第4区 |
| --- | --- | --- | --- | --- |
| 音色 | 八成分参数钢琴 | 风琴 | 正弦 | FM电钢琴 |
| 音区 | 低两八度（-24半音） | 低一八度（-12） | 标准（0） | 高一八度（+12） |
| 录放 | 开始录制 | 结束录制 | 回放实体琴键录制 | 全部停止 |
| 曲谱/指引 | 播放当前曲谱 | 停止曲谱 | 开启灯光指引 | 停止指引 |

音区是对既有25键音高的整体移调；默认25键C4–C6，标准区保持C4–C6。改音区影响之后按下的音，已按住的键仍按原音高松开。上传并提交曲谱后，当前曲谱可以变为用户上传谱；需要内置谱时在客户端选择内置谱。

模式同步版电脑/手机能读取板端当前页面、音色、音区、录放和指引状态。OLED只有独立连接示例，板级引脚仍未确认，不能把已有界面显示当作新增OLED已经接好。

## 新代码如何分工

| 文件 | 职责 |
| --- | --- |
| `desktop/web/keyboard-bindings.js` | 默认25键、合法按键、唯一性及冲突检查、实时布局模型 |
| `desktop/web/keyboard-shortcuts.js` | 设置界面、按键捕获、草稿/保存/取消、键盘输入分发 |
| `desktop/web/keyboard-shortcuts.css` | 沿用原界面风格的快捷键设置面板 |
| `desktop/preferences.py` | 独立本机配置文件、严格校验、原子替换、损坏提示 |
| `desktop/native_host.py` | 暴露读写偏好API，调用存储模块；原BLE驱动保持 |
| `desktop/web/app.js` | 调用新模块并更新琴键标签，复用原演奏及释放逻辑 |

## 实际验证

数据模型测试通过：默认布局、草稿不影响当前演奏、重复拒绝、保留键、清除、恢复默认。4项Python实际临时文件测试通过：保存重开一致、坏输入不覆盖、损坏文件保留、数字及标点支持。

独立无头浏览器通过：真实keydown/keyup、改Z为A、冲突、捕获不发音、输入框/IME防误触、Esc全停、20次快速弹奏共40条完整事件、保存释放、保存失败不改变实时布局、迟到启动读取不覆盖草稿、跨网页来源恢复、重置和无横向溢出。原电脑控制器、队列、曲库和整套界面回归通过。

Windows便携程序实际重新打包，新增偏好模块参与打包自检及源文件校验。未操作用户当前程序、未扫描蓝牙、未改FPGA或C3、未推送仓库。真实用户键盘布局/输入法及实物听感可在新程序继续验收。
