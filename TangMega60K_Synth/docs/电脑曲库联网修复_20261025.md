# 电脑曲库联网修复：2026-10-25

用户截图显示“联网失败，显示旧缓存”。这表示列表能够展示旧数据，不能作为实时联网成功的证据。

## 原因与修改

真实 `.exe` 的搜索和推荐均复现 `FileNotFoundError`。堆栈位于 `ssl.SSLContext.__new__`：本机所用 Python 发行版的 ssl 模块会读取同目录 `codex-rejected-cas.pem` 证书策略文件，原 PyInstaller 构建未包含该数据文件，导致 HTTPS 连接尚未建立就失败。

保持同一个诊断 EXE，仅补入与原 Python 完全相同的文件后，强制联网查询返回 10 首搜索结果、6 首推荐，均 `cached=false`、`offline=false`。没有放宽证书校验、修改系统代理或操作硬件。

| 文件 | 职责 |
| --- | --- |
| `desktop/build.ps1` | 从实际构建用 Python 查找附属证书文件，原样打包到 `_internal`，校验并记录 SHA256；标准发行版没有该文件时不强加此依赖 |
| `desktop/native_host.py` | 自检实际创建 HTTPS 上下文，检查证书验证和主机名检查；增加独立曲库诊断命令 |
| `desktop/score_library/diagnostics.py` | 强制联网搜索/推荐，分别记录结果、错误堆栈和耗时，不初始化 BLE/UART，不播放或上传 |
| `desktop/score_library/mutopia.py` | 回退旧缓存时保留原始失败原因 |
| `desktop/web/score-library.js` | 显示“实时联网 / 本机缓存 / 联网失败”及错误原因，全部按纯文本显示 |
| `desktop/tests/test_catalog_diagnostics.py` | 缓存结果不能误判联网通过、错误传播和错误长度限制 |
| `desktop/tests/test_recommendation_ui.cjs` | 原曲库界面回归，额外验证错误原因显示和 HTML 注入防护 |

程序版本标为 `1.2.1-local`，保留原曲谱推荐、MIDI 导入、自定义快捷键、模式同步和低延迟连接。音频 RTL、手机和 C3 本次未改。原客户端目录保留；新程序放在 `delivery-search-fixed/windows/TangNeonStudio/`。

## 复现与验证

在工程目录运行；Python 环境先按 `desktop/requirements.txt` 安装，具体工具路径可自行指定。

```powershell
./tmp/desktop-python/Scripts/python.exe -m unittest discover -s desktop/tests -p test_catalog_diagnostics.py -v
./tmp/desktop-python/Scripts/python.exe -m unittest discover -s desktop/tests -p test_music_library.py -v
./tmp/desktop-python/Scripts/python.exe -m unittest discover -s desktop/tests -p test_recommendations.py -v
# UI 测试需 Playwright/Chrome 及 mobile/tests/make_midi_fixtures.py 生成的测试输入
$env:TANG_UI_OUTPUT = './verification/search-check/ui'
node desktop/tests/test_recommendation_ui.cjs

./desktop/build.ps1 -SkipInstall -OutputDirectory './delivery-search-fixed/windows' `
  -EvidenceDirectory './verification/search-check/final-package' `
  -BuildDirectory './tmp/desktop-pyinstaller-search-fixed'
# 只检查依赖和 TLS，不联网，也不启动 GUI：
./delivery-search-fixed/windows/TangNeonStudio/TangNeonStudio.exe --smoke-test --smoke-output './verification/search-check/manual-smoke.json'
# 明确访问公开曲库；不读取用户曲谱，不连接设备：
./delivery-search-fixed/windows/TangNeonStudio/TangNeonStudio.exe --catalog-check --catalog-output './verification/search-check/manual-network/catalog-check.json'
```

诊断使用输出文件旁的独立 `catalog-check-cache`，查询强制联网。只有搜索和推荐都返回非空数据且未回退缓存，才标记通过。`verification/search-check/` 保存修复前/后与最终打包的实际记录。

此前的纯导入自检和替身网络测试未覆盖打包后创建 TLS 上下文这一环节，因此没发现遗漏。这次增加实际 TLS 检查，联网验收采用打包 EXE，不再仅凭源码能联网或缓存有卡片判断成功。整机无线/发声延迟和 FPGA 验收不属于此次修复结果。
