# 蓝牙实时曲谱播放（上位机版）

本次实现电脑端1.4.0-local、Android端1.8。复用已有蓝牙NOTE、状态查询和停止指令；声音继续由FPGA逐声部、逐样本生成。FPGA RTL、C3固件和`.fs`未改动。

## 使用步骤

1. 连接运行标准主工程的FPGA，等软件显示FPGA握手通过。可以沿用DirectScore1024位流。
2. 搜索曲目或打开本地MIDI，选择音轨、时间片段。
3. 将“播放方式”选为“蓝牙实时播放 · 曲谱留在上位机”。分析片段，确认转换提示后导入。
4. 在“当前曲谱”区域点击“蓝牙实时播放”。不需要先上传到FPGA。
5. 点击“停止实时播放”结束；原来的“停止曲谱”和“全部停止”也会停止实时任务。Windows窗口切到后台不会主动停止，关闭程序或断开设备仍会停止。

上位机生成的JSON实时曲谱包含`transport:"realtime"`，不能误走上传流程。键位版短曲谱也能点击实时播放，开始时会把键位按当前映射换成音高快照。板上内置曲谱没有本地事件，请用已有“小星星”或MIDI导入。

## 能播放多少音

- MIDI音高0–127，不受实体25键音域限制。例如一首曲子先后包含60种音高可以发送。音色在各音区的听感仍取决于现有音源参数。
- 曲谱存放在电脑/手机，最多100000条事件、6小时；上传后脱机播放仍受板上256/1024行容量限制。JSON导入/导出上限16MiB，原始MIDI限制仍为4MiB。
- 仍然共用现有64声部，释放尾音也会占用声部。实时通路当前使用来源63，与上位机虚拟琴键相同；播放期间不发送虚拟琴键，实体琴键可继续演奏，但需要为其预留声部。
- 开始前读取板上状态，拒绝在录制中启动，并停止板上原有曲谱。以开始时的当前音色演奏，不导入MIDI乐器切换、踏板、弯音等控制。相同音高跨轨重叠按原转换规则合并，并显示提示。
- 没有逐键灯光指引；上位机实时任务不会让板上`playing/scorePosition`变为实时曲谱进度，实时进度由软件单独显示。Windows版切换到其他窗口后继续调度；电脑休眠、结束进程或断开蓝牙无法继续发送。

## 时间与错误处理

所有事件都以同一个单调时钟起点计算预定时间。例如每100ms一个音，不会因为上一条确认花了10ms就把下一条改成110ms后再发送。

每次只提交一条曲谱NOTE并等待原协议确认，保持事件顺序，不将整首曲子提前塞进命令队列，也不静默删除短音。同一时刻的和弦仍需逐条传输，无法保证严格同时到达。界面的“最大发送至确认滞后”包括定时唤醒、排队和确认时间，**不等于DAC实测发声延迟**。

如果发送/确认比曲谱计划落后超过250ms，任务报错并释放本次音符。250ms是本版中止阈值，不是比赛延迟指标或延迟承诺。高密度和弦可减少伴奏音轨或在MIDI工具中降低速度。要消除无线到达抖动，需要后续板端时间戳缓冲，本次上位机版不具备这一功能。

停止发生在NOTE ON等待ACK时，先取消未来事件，等待该指令落定后再释放，避免先松开后按下造成长音。断线会中止任务，不会把旧任务交给新连接；真正断链时松键无法保证送达，依赖原有FPGA通信看门狗回收远程音符。Windows版失去焦点或最小化时继续调度；回来后可查看进度。电脑休眠、结束进程或断开蓝牙时无法继续发送，重新连接后需要重新开始，不提供断点续播。

## 本轮问题与修复

- 导入器原有1024事件限制阻挡长曲谱：增加显式实时模式，原上传模式的容量检查继续有效。
- 浏览器的定时器直接作为对象方法调用会触发`Illegal invocation`：改为包装函数，并在真实无头浏览器复测通过。
- 电脑失焦原先只释放全部虚拟音符，实时任务仍可能继续：改为取消实时任务并完成释放。
- 部分Node24测试就绪检查出现`undici`断言：改为读取完整本机HTTP响应，再运行既有界面回归。

## 验证与交付

在工程目录运行：

```powershell
.\scripts\test-realtime-score.ps1 -IncludeUI
```

需要项目现有Python虚拟环境、Node、Playwright及Chrome。UI测试使用独立无头浏览器、本机服务器和协议模拟器，不操作用户窗口或板卡。

日志在`verification/realtime-score/`，交付文件在`delivery-realtime-score/`。验证包括：统一时间基准、和弦事件顺序、1200事件完整发送、等待确认期间停止、长休止符停止、过载、断线、两端MIDI转换一致、两端界面播放/停止/重启/后台释放，以及原有上传和模式回传回归。Android另外执行APK组装、lint和签名检查；Windows执行打包依赖自检及静态资源哈希核对。

**真实蓝牙整曲播放、DAC听感、和弦到达抖动、比赛端到端延迟：待实测。未自动连接或下载板卡，未推送远端仓库。**
