# 桌面电子乐器采购清单（选型草案，2026-09-17）

范围：Sipeed Tang Mega 60K + NEO Dock；8个和弦按钮、4个压力演奏垫、独立压力增益/滑条弯音/旋钮颤音；目标64复音、2种以上合成音色、FPGA效果和LED曲目指引。数量按一套整机，加少量备件列出。已有器材不重复采购。

本表是可实施方案的备料清单，不代表模块已经买到、装配电路已经定稿或整机已经通过验收。板卡丝印、实际模块原理图、GPIO供电与余量、外壳孔位尚需核对；供应商的替代型号不能视为自动兼容。当前未核实闲鱼库存和成交价格。

## 音频方案的重要核对

官方NEO Dock-60K 31004原理图（Rev 1.4，2025-03-31）第10页，U16为PT8211-S，U20为NS4263。PT8211采用16位LSBJ/右对齐格式；工程现有i2s_tx为24位Philips I2S、每声道32个BCLK。不能只因网络名写着I2S就直接沿用发送格式。

本清单选外接PCM5102A成品DAC模块，使用标准I2S，再连接有源音箱。原有板载PT8211和扬声器端子不属于这条外接音频链。若将来使用板载音频，需要独立适配、验证串行格式，并明确比赛的I2S要求。

PCM5102A的模拟输出是线电平，不直接驱动低阻耳机或无源扬声器。模块需具备完整稳压、去耦、滤波和输出插座，并提供原理图；确认其实际VIN电压、I2S格式配置、SCK无外部MCLK时的处理及静音脚状态。芯片可采用3线I2S，但模块的接法必须按实物原理图确定。

B01六个功能建议为音色、和弦模式、八度上/下、效果开关、静音/协调复位。紧急静音/复位的最终接法需单独定义；若作为硬件复位，不能只通过正在工作的移位扫描链实现。

ADC通道分配：CH0~3=四演奏垫，CH4=独立全局压力，CH5=弯音滑条，CH6=颤音旋钮，CH7=预留/效果旋钮。四演奏垫是手指压力触发方案，不是压电鼓棒打击方案。压力幅值到velocity的映射需要标定，不能直接称为物理击键速度测量。

MCP3208在低供电下的最高采样率与5V规格不同；按数据手册选择SPI频率和采集时序。缓冲/RC须验证建立时间，滤波和力度采集窗口计入延迟，不能通过长时间等待峰值满足力度功能却忽略10ms要求。

## 无需因64复音额外购买

不需要64个DAC、64个扬声器、64个按键、独立DSP芯片、Arduino/STM32音源、树莓派/RK3588或预录音频播放模块。无需为了基本合成另买DDR3、Flash、独立JTAG下载器；有NEO Dock时先用板上已有资源。没有定义续航目标，暂不采购锂电池、充电板或升压板。

## 分批采购和待定项

第一批：核对已有板卡和电源；A06/A07/A08；至少1路FSR和引线、滑条、旋钮；ADC及缓冲；少量按钮、移位芯片、阻容、原型板和连线；准备可借用的测量设备。

第二批：原型测通后补齐5路FSR、14按钮、16指示LED、OLED和完整线束，安装一套完整面板。备件数量可合并下单以节省运费。

第三批：布局/电气审核后加工外壳及可选PCB；需要无线/录音时再采购G组并定义协议。

尚需用户/实物信息：核心板和底板丝印及所含配件；音箱/万用表等已有物品；所选模块完整商品页和原理图；最终面板安装孔距。外壳、接口总线和电源极性在这些信息确认前不按猜测下单。
