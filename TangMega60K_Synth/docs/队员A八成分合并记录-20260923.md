# 队员A八成分钢琴合并记录（2026-09-23）

合并来源为 `EightPiano_20260923` 交付包。先按交付包的 `SHA256.json`
逐一校验了 268 个文件，均与清单一致。包内 `先读说明.md` 是交付说明；
主工程以当前 48 kHz 时钟、标准 I2S 和板级自检为基线，只合入与新音色有关的
RTL、参数 ROM、离线模型、复测脚本和文档。

## 接入内容

- V2 音频接口保持不变。`event_timbre=2` 选择四音区八成分钢琴；
  `event_timbre=0/1` 继续为正弦/风琴。独立 `audio_system_v2_fm` 顶层允许
  `event_timbre=3` 选择可选 FM 电钢琴，普通板级工程默认不开 FM。
- `voice_engine`、`adsr`、`wavetable_rom` 和 `audio_system_v2` 接入新音源；
  `polar_lane`、FM lane、四份新 ROM 以及 `assets/audio` 的模型和授权文件
  一并加入。所有六个用到完整音源的 Gowin 工程均列入 `polar_lane`，
  两份 48 kHz 构建脚本会复制新 ROM。ModelSim 音源和 Live64 入口亦已更新。
- 可选 FM 顶层的独立测试脚本、逐键导出脚本和
  [FM 电钢琴说明](FM电钢琴实验.md)也已带入，供后续选择音色 3 时复测。
- 保留主工程的 `rtl/i2s_tx.v` 首样本预备修复、
  `sim/tb_i2s_tx.sv` 回归以及现有 GAO/I2S 位流；交付包的旧 I2S 发送器
  和旧发送器测试台没有覆盖主工程。
- 队员A的四音区参数、C4–C6 音域及听感局限见
  [八成分分区钢琴](八成分分区钢琴.md)。参考录音未作为 PCM 音源存入 FPGA。

## 当前验证

- 新音源的 ROM 用交付模型离线重建，四份新 ROM 的哈希与交付包一致。
- ModelSim 四音区测试通过；当前 RTL 生成的 864,100 帧立体声样本与
  独立定点模型逐样本一致。钢琴 4/64 声部回归均通过，帧内计算分别为
  69/969 个时钟。钢琴 64 声部、延迟开启的 I2S 对拍通过 12,062 帧，
  启动及稳定运行欠载均为 0。可选 FM 的 4/64 声部回归均通过，帧内计算
  分别为 53/713 个时钟，两次均为 0 错误、0 警告。主工程旧音色 4 声部
  和 DSP 单元回归通过。
- 六组 Icarus 控制/I2S 回归通过。48 kHz 外置 I2S 板级仿真通过
  启动、停止、再次启动和复位检查，欠载为 0；原 GAO 板级自动运行仿真
  通过两轮启停及第三轮重启。
- Live64 的事件源与音频边界用例分别通过，覆盖 65 个事件场景、
  32 次保持音重触发和 32 条快速尾音；两个阶段均为 0 错误、0 警告。
  本次为控制运行时间在频谱采集前停止，未运行后续 FFT 分析，
  因此不把 `test-live64.ps1` 整体报告为通过。
- 合并后独立 `audio_system_v2_fm` 综合通过：逻辑 5493/59904，
  寄存器 4034/60780，BSRAM 70/118。合并后外置 I2S 工程在独立目录
  完成综合和布局布线，Setup/Hold 违例均为 0；49.152 MHz 音频域
  Fmax 为 72.536 MHz，BSRAM 72/118，DSP 27/118。

独立布线仍报原有 PR1014：底板 50 MHz 时钟接在非专用 GCLK 引脚 V22。

全部 32 个比率值都小于 2^27，最高位为 0。两者均未造成当前构建失败。
