## 2. 4 声部与 64 声部分开验收

| 项目 | 4 声部实例 | 64 声部实例 |
|---|---:|---:|
| ModelSim 结果 | PASS | PASS |
| 输出样本总数 | 81,188 | 81,366 |
| begin 提交沿至 FX_SEND 的最大周期数 | 45 | 585 |
| 中性参数与固定中性参考逐位相等 | 9,804 帧 | 9,804 帧 |
| 满载分配、拒绝额外音符 | 4/4 | 64/64 |
| 同时释放、done 反压后回收 | 4/4 | 64/64 |
| 额外两次独立尾音测试后累计 done | 6 | 66 |

参考实例是同一新核心的 EXPRESSION_ENABLE=0 固定中性路径，不是历史旧音源。此比较可以发现 V2 中性参数造成的额外幅度或音高改变，但不能替代对全部算法的独立数学验证；下面另有频率、频谱、单位算术和时序断言。

两种声部数均覆盖：

- 原 cmd/done/sample 握手；同音高不同 source 的分配独立性（source 只在队长分配器中出现）。
- 每声部相位与状态独立；改频、重新触发、释放不串扰其他声部。
- begin 后下一拍读取本次提交参数；同一帧全声部使用同一份参数。
- gain、bend、vibrato 三个限速平滑器逐帧推进量核对；LFO 每帧恰好推进一次。
- sample 反压时 valid、左右样本保持，所有声部相位、LFO 和参数平滑暂停。
- 反压期间收到新表情事件，active 参数到下一次 begin 才提交。
- done 反压时负载稳定；RELEASE 到零才上报一次；gain=0 不误回收。
- 满载释放、再分配、输出受阻时复位，不残留旧声部或旧输出。

585 周期是上述计算区间的计数，不是完整按键到声音延迟，也不代表布局布线后已实现 49.152 MHz。实际连续供数另由 I2S 闭环检查。

## 5. 64 声部 + 延迟 + 原 I2S 的闭环

使用 audio_system_v2_delay、原 captain_system_top_v2 与原 i2s_tx，不用替代 I2S 模型。外部串行接收器检查 I2S 一位延迟、32 位槽、填充位，并逐帧比较接受的左右 PCM。

实际结果：

```text
AUDIO I2S INTEGRATION PASSED voices=64 delay=on
frames=10862 nonzero=10859
steady_underrun_delta=0 startup_underruns=1 stalls=4712617
```

64 个不同音高（MIDI 36..99），交替音色；运行中改变三项表情，再释放全部音符检查回收。4712617 为观察到的反压时钟数，不是丢样本数。

启动阶段有 1 次 underrun，是引擎初始化/填充前的空 FIFO；在 200 帧预热后统计窗口内新增 underrun 为 0。没有隐瞒启动空帧，也不把它计作稳态断流。

新增全部 ModelSim 编译/仿真结束统计：0 errors、0 warnings。原队长六组回归全部完成；其 tb_control_v2 原有 11 个未连接端口警告仍保留，没有为消除这些警告修改公共文件。

## 7. 未完成与协议待定

- 板级 PLL/CST/复位/DAC 配置、SDC、布局布线时序收敛和上板试听尚未完成，不能直接声称达到整机硬件验收。
- V2 没有独立滑音/连奏、实时 ADSR、声像或效果器控制协议。本版实现全局弯音平滑和静态可旁路延迟；未私自扩展公共接口。
- 高音区减去过高谐波，最终基频夹到 0.45Fs；超范围大弯音会被限高。
- 音色/力度突变和波表分区切换仍可能留下听感痕迹，未做交叉淡化。合唱和混响未实现。
- 全局增益在延迟前；开启延迟时降到零仍保留逐渐衰减的回声。整机“立即静音并清除回声”需队长共同定义后级 mute/clear 语义。
- 没有用户旧音源，不能声称通过旧音源回归；中性兼容的严格定义见第 2 节。

完整模块说明及接线见《音频引擎V2实现与接线.md》。本轮只在个人分支工作，未 push、未合并 main。
