# AHCT125 LED R1 成品制作说明

目标是收到包含全部9个元件、已焊好连接器的成品板。只下 PCB 裸板订单，或只选择贴片元件装配，均不满足这个目标。

## 工艺与装配范围

- PCB：单板40×30mm；双面FR4，厚1.6mm，1oz铜厚；两个直径3.2mm安装孔。
- SMT 共5件：U1、R1、R2、C1、C2。
- 插件共4件：J1、J2、J3、C3。需明确选择插件插装及焊接服务；如供应商的SMT订单不含插件，需另外安排该步骤。
- J1/J2按公排针装配，避免误采购成母座。J3装配后，应能从板边插线并操作螺丝。
- C3有极性：正极接+5V、负极接GND。实际物料为Rubycon 1000µF/10V、直径8mm、高11.5mm、脚距3.5mm；机械检查按11.5mm高度，不能按库中8mm高的模型标题判断。
- 采购及替代以最终BOM、封装及厂家审核为准。U1必须为AHCT输入门限器件；不能仅因脚位相同而换成AHC或HC系列。

## 上传文件与工厂代拼板

优先提交单板制造文件，让工厂按其SMT/插件工艺代拼板：

- `Gerber_AHCT125_LED_R1.zip`：40×30mm单板Gerber及钻孔。
- `BOM_AHCT125_LED_R1.xlsx`：原生导出BOM。
- `CPL_AHCT125_LED_R1.xlsx`：原生导出单板贴装坐标。

本次原生`.csv`文件实际上是UTF-16LE编码、TAB制表符分隔。若对方要求文本格式，必须明确编码和分隔符或经校验后转换，不能假设是逗号分隔。BOM、坐标和Gerber都按单板提交时，需由工厂生成与其拼板一致的装配数据；不要将单板坐标冒充已经平移复制好的拼板坐标。

## 2×2拼板概念：两个不同选项

以下均为**待制造商审核的方案**，没有包含已经批准的拼板制造文件。工厂也可根据其设备给出其他拼法。

### 选项A：零间距V割，90×70mm

40×30mm单板，2列×2行，相邻板之间零间距，四周每边5mm工艺边：宽`2×40+2×5=90mm`，高`2×30+2×5=70mm`。

此选项必须由工厂确认V割线可贯通、两侧元件/铜皮到V割线的距离、剩余板厚、分板应力、插件与电解电容避让，以及工艺边定位孔/Mark点。尺寸算对不代表V割工艺已被批准。

### 选项B：2mm间距铣槽/邮票孔，92×72mm

若厂家要求拼板，可提交如下概念供其审核：

| 项目 | 概念尺寸 |
| --- | --- |
| 单板 | 40×30mm |
| 排列 | 2列×2行 |
| 板间距 | 横向、纵向均2mm |
| 四周工艺边 | 每边5mm |
| 整体外形 | **92×72mm** |

计算为：宽`2×40+2+2×5=92mm`，高`2×30+2+2×5=72mm`。这是几何概念，**不是已完成的拼板制造文件**。

请制造商确认铣槽、连接桥/邮票孔、工艺边、定位孔、Mark点、元件与分板处距离，以及插件/电容的装配空间。不可把此2mm间距铣槽概念与选项A的零间距V割混为一谈。若制造商采用其他拼板要求，以其审核后的拼板图为准。

## 装配后验收范围

至少包含电源短路检查、C3极性和9件物料核对、焊点及针号检查。通电使用合格稳压5V与匹配线材，从少量灯低亮度开始，核对3.3V输入到5V输出、LED DIN脉宽及供电跌落。

PCB/SCH规则检查、元件采购、SMT、插件焊接和实物功能测试是不同步骤。订单中未包含或尚未完成的步骤应如实保留为待办，不能宣称已经装配或通过稳定运行测试。J2兼容杜邦连接，但未知杜邦线不按2A承诺；供电通流仍需结合最终铜皮、线材、接触件和温升实测。

若制造商要求改线、改孔或改外形，需重新维护固定地铜、运行原生DRC并重新导出核对Gerber。底层固定FILL不会因普通铺铜快捷键自动更新，不能仅按`Shift+B`就沿用旧检查记录。
