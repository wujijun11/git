# 74AHCT125 LED 电平转换板 R1

为本项目 FPGA 的 3.3V LED 数据输出转换为 5V，连接 25 灯 WS2812B 灯板。电阻、电容和芯片均在板上；制作时需同时选择元件采购、SMT 贴装及插件焊接服务，收到焊好的成品后接线使用。

这是待制作、待首板验收的设计，不能视为已完成装配或实物稳定运行验证。检查记录见 [原理图独立审查](verification/schematic_review.md)和 [布局与地铜连通性审查](verification/layout_review.md)。制造与装配注意事项见 [成品制作说明](assembly_order_notes.md)。

本次原生原理图和PCB完整DRC均通过，未报告违规；交付副本在嘉立创EDA专业版V4.1.60重新打开后再次通过检查。制造导出的孔径、钢网开口和全部9个元件的BOM/CPL一致性也已核对，见 [制造文件审查](verification/manufacturing_review.md)。

## 接线

先断电接线，按 PCB 丝印确认针号，不能凭照片左右或线色猜。J1、J2 是公排针，配母头杜邦线；J3 是螺丝端子。

| 接口 | 针号 / 丝印 | 接到哪里 |
| --- | --- | --- |
| J1，FPGA 输入 | 1 / IN | FPGA J13-14，LED 数据输出 |
| J1，FPGA 输入 | 2 / GND | FPGA J13-12，公共地 |
| J2，灯板输出 | 1 / OUT | 灯板 DIN |
| J2，灯板输出 | 2 / +5V | 灯板 5V |
| J2，灯板输出 | 3 / GND | 灯板 GND |
| J3，外接电源 | 1 / +5V | 合格稳压 5V 电源正极 |
| J3，外接电源 | 2 / GND | 同一电源负极 |

连接关系：`FPGA J13-14 → J1 IN → 74AHCT125 → 板载330Ω → J2 OUT → 灯板DIN`。

J3 的 5V 同时给转换芯片和 J2 灯板供电；与 FPGA 通过 GND 共地。**外接 5V 不接 FPGA GPIO，也不接入 J1。** 灯板和转换芯片使用同一组 5V 电源，一起通断；本板不提供稳压或电源反接保护。

## 板上有什么

| 位号 | 元件 | 用途 |
| --- | --- | --- |
| U1 | SN74AHCT125DR，SOIC-14 | 单路 3.3V → 5V 数据缓冲；其余三路关闭 |
| R1 | 10kΩ | 输入下拉，断线时默认低电平 |
| R2 | 330Ω | 数据输出串联电阻 |
| C1 | 100nF，X7R | 芯片近端去耦 |
| C2 | 10µF / 25V | 本地电源滤波 |
| C3 | Rubycon 1000µF / 10V | 灯板电源入口储能；有正负极 |
| J1 | 2P，2.54mm 公排针 | 接 FPGA 数据和地 |
| J2 | 3P，2.54mm 公排针 | 接灯板数据、5V、地 |
| J3 | KF127-5.08-2P 螺丝端子 | 接外部稳压 5V |

PCB 为 **40×30mm，双面 FR4、厚1.6mm、1oz 铜厚**；设两个直径3.2mm安装孔，供 M3 螺丝及绝缘支柱固定。

## 首次使用

1. 将转换板放在灯板旁边，J2 到灯板使用短线；数据线与地线相邻走线。板载1000µF电容应靠近灯板供电入口。
2. 断电检查 J3 极性、J1/J2 针号及灯板 DIN。裸排针不能防反插，灯板自己的3P线序也必须逐线核对。
3. 外部电源和供电线应有足够电流能力；先测板上5V正确，再接入灯板测试。**排针额定电流不等于未知杜邦线、插簧和压接点都可承载2A，不能据此承诺整条连接的2A能力。**
4. 首板从少量灯、低亮度开始，逐灯确认方向、灯号与颜色，再验收整机控制。检查供电跌落、连接处温升，以及灯板DIN波形；未完成这些测试前，不把设计检查通过当作稳定运行证明。

转换板不改变灯板协议，也不会增加琴键本身的LED。当前工程仍由 FPGA 输出 WS2812 数据。

## 制作文件和后续编辑

BOM和贴装坐标优先上传原生导出的 **`.xlsx`**。本次原生`.csv`实际采用UTF-16LE编码、TAB制表符分隔，不能直接按逗号CSV导入。交付以40×30mm**单板Gerber、单板BOM和单板坐标**为准，可由工厂代拼板；拼板概念和审批范围见成品制作说明。

**底层地铜是固定FILL铜面，不是会随改线自动更新的动态铺铜。** 移动元件、改线、改孔或改外形后，须维护并重新生成地铜，再执行完整原生DRC、跨层连通性检查，重新导出并检查Gerber。当前生成器只覆盖本版的已知几何；新增底层焊盘或其他铜形状时也要扩展避让逻辑。按`Shift+B`不能当作这些固定铜面已重建的证明。
