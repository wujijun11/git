## 布板、装配及使用边界

1. C1 必须贴近 U1 的供电脚，缩短电源与回地回路。网表不能证明这一点。C3 应靠近 J2 电源出口；安装整板时靠近 LED 的 DIN/电源入口。
2. 外接稳压 5V 同时供 U1 和 LED；GND 与 FPGA 共地。J1-1 接当前项目 J13-14/A15；J1-2 接 FPGA GND。J2-1 只接 LED DIN，不接 DOUT。
3. 本电路没有反接保护、过压保护或电源限流。丝印不能替代这些保护；供电极性必须按 J3-1/J3-2 检查，不得将外接 5V 接到 FPGA GPIO。
4. J2 器件的排针额定电流不代表未知杜邦插簧、线径和压接点可持续承载 2A。成品通流能力需结合 PCB 铜宽、焊接、配套线材与温升确认；对未知杜邦连接仅作低亮度调试，不承诺 2A。
5. 裸排针没有机械防反插。J1/J2 应大字标注功能和每针信号；J2 中间脚是 +5V，不能凭常见灯板线序整排盲插。
6. 当前 U1-1 常使能，输入 10kΩ 下拉提供断线/FPGA 未驱动时的默认低电平；这并不是经过电源监控的无毛刺启动保证。TI 的输入快沿要求不宜用未经分析的 RC 延时替代。
7. AHCT 与 LED 若分别上电/断电，输出高电平可能通过未供电 LED 的 DIN 结构回灌。共用同一 5V 电源并一起通断；330Ω 只限流，不构成电源隔离。
8. 首板仍需测 LED DIN 的高低电平、0/1 脉宽及电源跌落。逻辑仿真和 SCH DRC 不能替代实物测量。数据线与地线成对、尽量短，避免未知长线电容。

## 非阻塞的元数据问题

网表中 C3 的 `3D Model Title` 为 `CAP-TH_D8.0-H8.0-P3.50`，但选定 Rubycon 物料的实际高度为 **11.5mm**。这不改变电气网络或 3.5mm 脚距，但 3D 装配/外壳避让应按实际高度检查，不能以模型标题的 8mm 为机械依据。

U1 库中多项逻辑脚的 ERC 类型均标作 `Passive`。因此 DRC 通过只是一项辅助证据；本次另行依据芯片功能逐针审查，不把 ERC 通过等同于电路功能证明。
