# Touch25 配套四电极电容滑条 R1

为现有25键 FPGA 合成器设计的独立无源滑条；连接第一块 MPR121 的 ELE8–ELE11。原25键 R1 PCB、映射及 Gerber 不变。滑条首版目标是单指连续弯音，默认建议 ±200 音分，松手回中。

当前状态：原生交换工程已成功导入；立创原生 DRC 已完成141项检查、0错误。原生导出的 `Gerber_Touch25_Slider4_100x20_R1_Release.zip` 已通过独立审计，73项检查全部通过；报告位于 `verification/`。

可编辑的 `Touch25_Slider4_100x20_R1_Release.eprj2` 已保存，尚未验证重新打开；`.epro2` 交换工程可导入。订单和出货以平台实际记录为准，实物焊接与校准仍待验收。MPR121采集与滑条RTL已实现并通过自动仿真，完整工程含候选GPIO约束；实际底板版本/管脚核对与实板下载尚未验收。详见 [MPR121 实现说明](../../docs/mpr121-implementation.md)。

## 设计与加工

- PCB 100×20 mm、双层 FR-4；首版建议加工5片，1.6 mm / 1 oz、绿色阻焊、白色丝印、无铅喷锡。名义滑动行程84 mm（标记x=8到92）；板长100 mm不等于100 mm有效行程。
- 顶层四组交错楔形电极，纵向连接脊宽0.50 mm，四横带镜像交错。竖向间隙0.30 mm，斜边最短净距约0.299 mm；这属于本项目首版参数，需实物验证。
- 触摸区顶层铜覆盖阻焊，无露铜/锡膏窗口。背面只布0.20 mm细线，不在敏感区铺实心地。
- J4 为2.54 mm 1×4通孔排针，孔1.0 mm / 焊盘1.8 mm，针1是方形。建议背面焊接，保持触摸正面平整。首版使用无铅喷锡即可，无需为了触摸选择沉金。
- 两个3.2 mm非金属化安装孔：(3,8.5)、(97,8.5) mm。使用绝缘支柱，避免触摸区下方金属或电源线。
- 可覆薄非金属保护膜，例如约0.2 mm PET加薄胶，避免空气层；覆膜后重新校准。贴膜厚度不是已验证的灵敏度保证。

## 接到现在的硬件

断电后接线。从触摸正面看、J4在下方时，针1在左；从背面看左右反转，以方形焊盘确认针1。

| 滑条 J4 | 网络 | 接第一块 MPR121 |
| --- | --- | --- |
| 1 | S0 | ELE8 |
| 2 | S1 | ELE9 |
| 3 | S2 | ELE10 |
| 4 | S3 | ELE11 |

**J4四针都是敏感电极，不接3.3V、5V、GND或FPGA GPIO。滑条自身不需要供电。** 原25键 J1仍接这块 MPR121 的 ELE0–ELE7，两者不会占用同一电极通道。

购买/准备1×4、2.54 mm公排针一条和4根短母对母电极线（取决于MPR模块已焊公排针）。电极线以≤50 mm为布置目标，把MPR1放到琴键J1和滑条J4之间；目标不包括板内走线，线越长越需要校准和抗干扰验证。固定线束，避开PCM5102A时钟、功放和喇叭线。

MPR121模块仍使用3.3V及公共GND，其 SCL/SDA/IRQ接 FPGA已核对的3.3V GPIO。滑条复用同一模块，所以在原三模块、三独立I²C总线方案上不增加FPGA引脚。[完整工程约束](../../full/contest_full.cst) 已按官方31004底板资料分配候选管脚；实际底板编号、接口和导通仍须核对，不应将候选约束视为所有版本通用。不能接板载按键的1.5V IO。

## 接到现在的 HDL 工程

信号链：`J4电极 → MPR121 #1 → I²C采集 → 四通道位置/触摸有效 → 弯音事件 → instrument_full_system → FPGA音源 / I²S / PCM5102A / 功放 / 喇叭`。当前入口为 [board_contest_full_top](../../rtl/board/board_contest_full_top.v)，采集由 [mpr121_input_frontend](../../rtl/sensors/mpr121_input_frontend.v) 与 [mpr121_slider](../../rtl/sensors/mpr121_slider.v) 实现；原板载按键工程不自动包含这些新增逻辑。

1. 第一块 MPR121：初始化时先写Stop `0x5E=0x00`，设置/读回配置，确保 `GPIO Enable(0x77)=0`，最后写 `0x5E=0x8C`，启用ELE0–11、关闭近接、沿用原CL=10。其余两块仍为 `0x88/0x89`。
2. 琴键仍使用 `touch_status & 0x00FF`，滑条状态单独为 `(touch_status>>8)&0x0F`；不能把滑条四通道并入25键位图或触发四个新音符。
3. ELE8–11 的10位滤波数据地址 `0x14–0x1B`（低字节在前）；8位基线地址 `0x26–0x29`。每路使用有符号 `delta=(baseline8<<2)-filtered10`，再做无触摸噪声补偿和各通道灵敏度归一化。负数先夹到0，不允许无符号下溢。
4. 用归一化权重求位置 `p=(0*w0+1*w1+2*w2+3*w3)/(w0+w1+w2+w3)`，总权重低于实测门槛时判定松手，不做除0。装配后测量真实左右端点，对p再次归一化到0..1并夹紧，再映射 `bend=round((2*p-1)*200)` 音分；中点设置小死区、位置变化设置小迟滞。初版只保证算法定义，不保证线性/分辨率。
5. 前端通过 `expr_update_valid/ready` 提交：`expr_update_mask=3'b010`、有符号13位 `expr_update_bend_cents`；未选中的gain/vibrato字段保持合法值。完整工程由表情仲裁器合并手机与滑条更新；valid高而ready低时保持全部字段，直到接受。该接口是全局弯音，会作用于正在发声的所有音符。
6. 完整工程已连接滑条表情输入。松手或MPR1故障使弯音回0，MPR1故障还释放其8个琴键，健康MPR2/3不清空。25琴键使用source25–49，曲谱使用0–24，滑条只更新表情，不占用额外音符source。实际必须下载通过板卡/管脚核对与布局时序检查的新完整工程，不能只插上滑条就期待原板载按键下载文件响应。

IRQ只反映触摸/释放变化，不足以捕捉在同一电极区域内的滑动，必须周期读取模拟数据。[NXP数据手册 §5.3](https://www.nxp.com/docs/en/data-sheet/MPR121.pdf)定义连续读取0x00–0x2A得到一致快照：43数据字节，含通常随机读3个地址阶段约414个SCL周期。当前默认49.152MHz/400kHz参数的实际RTL事务为1.062968ms；完整快照接受后等待0.5ms再读，健康低IRQ可提前。无背压/重试/拉伸时，已经形成的新寄存器状态到提交的保守数字预算约2.628ms，滑条计算另约1.364µs；这不包括MPR内部SFI4/ESI1ms过滤、真实触摸阈值和音频/DAC。先验证400kHz读回及超时，再测触摸到声音总延迟；不能据此宣称物理≤10ms、≤5ms或无抖动。

单指滑条不能区分双指，双指会生成合成位置。它不测真实压力或击键速度；琴键控制音高、滑条控制弯音形成两种操作，赛题的“独立演奏维度”仍需结合正式规则与实物演示确认。

## 到货后的验收

1. 未接模块、断电，检查J4每针到对应电极导通，各不同网络无短路；只用万用表不能验证连续位置或延迟。
2. 安装膜和绝缘支架，接MPR1，记录无触摸与左/中/右单指原始数据；调整每路噪声门槛、增益及端点，确认沿条位置单调。
3. 按住琴键，同时沿滑条移动，应听到音高连续变化；松开滑条回原音高，松琴键停止。测试多琴键和MPR模块故障隔离。
4. 用示波器/逻辑分析仪标记输入事件与I²S样本，测实际端到端延迟；观察音频时钟、功放工作与线缆移动是否引起误触。
