## 面板规格

| 项目 | 设计值 |
| --- | --- |
| 音域 | C4–C6，MIDI 60–84，共25个半音 |
| 琴键 | 15个白键位置、10个黑键位置；平面触摸，无按压行程 |
| PCB | 双层，290 × 105 mm；建议1.6 mm FR-4 |
| 白键节距 | 18 mm |
| 白键电极 | 16 × 28 mm，圆角半径1.5 mm |
| 黑键电极 | 11 × 25 mm，圆角半径1.5 mm |
| 外观建议 | 黑色阻焊、白色丝印；白键由轮廓及音名识别 |
| 电极表面 | 顶层铜覆盖阻焊，不开露铜或锡膏窗口 |
| 信号接口 | J1：1×8；J2：1×8；J3：1×9，均为2.54 mm排针 |
| 连接孔 | 1.0 mm通孔、1.8 mm焊盘；pin1为方形焊盘 |
| 转层孔 | 0.3 mm孔、0.8 mm焊盘，焊环0.25 mm；上下阻焊扩展−0.4 mm，实际Gerber确认双面盖孔 |
| 最小丝印 | 字高1.0 mm，线宽0.15 mm |
| 安装孔 | 六个3.2 mm非金属化通孔；下中孔已改到(170,100) mm |

面板没有 MCU、MPR121 芯片、音频电路、SCL/SDA、VCC或GND接口，也没有地平面。不能单独发声。工程预览中的半透明色用于显示被阻焊覆盖的电极位置，不能当作实物照片或实际铜面颜色。

## 电极连接

| 面板接口 | 琴键网络 | 外接模块 | 模块触摸通道 |
| --- | --- | --- | --- |
| J1 pin1–8 | E00–E07 | MPR121 #1 | ELE0–ELE7 |
| J2 pin1–8 | E08–E15 | MPR121 #2 | ELE0–ELE7 |
| J3 pin1–9 | E16–E24 | MPR121 #3 | ELE0–ELE8 |

三个接口只传电极信号。**面板上的这些针脚接 MPR121 的 ELE端，不能直接接 FPGA GPIO，也不能接3.3V、5V或GND。** 从面板正面看，各接口pin1在左，信号按音高从左到右增加；从背面看左右会反转，请识别方形pin1。

将三块模块放在对应接口附近，电极连接线以 **不超过5 cm** 为布置目标，尽量避开DAC时钟线和功放/喇叭线。使用三个独立 I²C 总线：每块模块的 SCL、SDA、IRQ分别接FPGA，共占9个GPIO；模块另接3.3V和公共GND。按目前仅DAC占用三路PMOD信号的接线，13个空闲GPIO接完后剩4个。具体FPGA针脚必须由约束文件分配到已确认的3.3V GPIO。

完整装配步骤和25键逐针表见 [装配与接线指南](assembly_wiring_zh.md)。
面板侧优先采用2.54 mm的8/8/9针成组母壳，两端标明J1/J2/J3及pin1；模块端按实物ELE标注核对，不能默认两端直通。模块放在下沿外绝缘托架，量实物后确定固定方式；详见 [线束与底托方案](harness_assembly_zh.md)。

## 还需要准备

- 三块 MPR121 模块，优先选择排针已焊版本；模块使用3.3V供电及3.3V数字电平。
- 1×8公排针两条、1×9公排针一条，需要自行焊接；本面板没有SMT器件，普通PCB打样不会自动焊排针。
- 25根短电极信号线。面板侧用2.54 mm的1×8母壳两只、1×9母壳一只及匹配端子；模块侧公排针可用1P母端逐针接线，核对ELE物理顺序后再考虑成组插头。电极线另作拉力固定。
- 模块到FPGA的9根数字信号线及3.3V/GND分配线。模块公排针到FPGA PMOD插孔通常使用公对母线。
- 六套M3绝缘支柱/螺丝及安装底板；避免PCB背面焊点碰金属。
- 可选薄PET保护膜。加膜后重新校准触摸阈值，并重新测试响应。

当前FPGA工程还需要增加MPR121初始化、三总线触摸读取、25键音符映射与校准。触摸开/关不能作为已经测得的压力或击键速度；项目要求的第二种独立演奏维度应另接合适传感器。端到端触摸→声音延迟仍需实测，不能用芯片采样间隔或软件预检代替。
