# Touch25 R1 装配与接线

**本指南对应290 × 105 mm、25键C4–C6的R1打样版。最新安装孔下中坐标为(170,100) mm。最终原生工程已完成141项DRC、0错误，实际Gerber的163项独立检查及ZIP/映射核对通过；订单生产与出货以立创平台实际记录为准。**

优化装配优先按 [成组线束与底托指南](harness_assembly_zh.md) 进行；面板侧8/8/9针母壳、pin1标记、线束拉力固定及模块下沿外布置见 [示意图](harness_layout.png)。该图不代表模块实物尺寸，底托应量实物后制作。

## 先识别接口

面板的J1、J2、J3只有触摸电极信号，不需要数字供电。它们全部接到MPR121的ELE电极输入，不能接到FPGA GPIO或电源。

面对面板正面的琴键和音名时，各组排针从左向右是pin1、pin2……；pin1焊盘为方形。翻到背面后左右会反转，不要直接按背面“从左到右”接线。

背面另外印有0～7（J3为0～8），这些是对应MPR121的ELE通道号，不是从0开始的物理针号。方形焊盘对应正面pin1、背面通道0，即ELE0；正面pin8对应背面通道7，即ELE7。

## 焊接和固定

1. 所有外接板先断电。在J1/J2焊1×8公排针，在J3焊1×9公排针，间距均2.54 mm。先焊一个端针，确认垂直后焊其余针。
2. 检查相邻焊盘是否连锡。三块MPR121先不接入，断电用万用表检查排针间不存在持续接近0Ω的短路，并检查每根杜邦线的两端导通。
3. 用六个3.2 mm安装孔和绝缘支柱固定PCB。孔中心为(5,5)、(145,5)、(285,5)、(5,100)、(170,100)、(285,100) mm；背面焊点与金属底板保持隔离。
4. 将模块#1/#2/#3分别固定在J1/J2/J3下沿外的绝缘托架，尽量避开有效电极投影；按上表连接三组8/8/9根电极线。面板侧插头成组并标pin1，模块侧逐针确认ELE物理顺序，不能默认左右直通。电极线实际总长以≤5 cm为目标，远离DAC时钟及功放输出线，在托架处固定线束以分散拉力。

电极铜被阻焊覆盖是正常设计，无需刮掉阻焊。可选贴薄PET膜保护表面；贴膜会改变触摸条件，应在贴膜之后完成最终阈值校准。

## 模块接到FPGA

三块模块使用三个独立I²C总线，因此可以使用相同器件地址；驱动仍须验证每块实物的地址，不需要为了共享总线强行改ADD接法。

| 每块MPR121引脚 | 接到哪里 |
| --- | --- |
| 3.3V/VIN（按模块标注） | 已确认的3.3V供电分配点 |
| GND | FPGA公共GND |
| SCL | 该模块独立的FPGA时钟GPIO |
| SDA | 该模块独立的FPGA双向数据GPIO |
| IRQ | 该模块独立的FPGA中断输入GPIO |
| ELE0… | 上表对应的面板电极；不接FPGA GPIO |

三个SCL、三个SDA、三个IRQ合计占9个GPIO。完整工程将它们分配到J13，并为UART和LED另分配3个信号；不能沿用早期“PMOD还空闲多少”的估算接线。3.3V/GND电源脚另算。具体针号见 [完整工程接线](../../docs/全功能工程与官网验收-20261011.md)，上板前核对实际底板版本，不能把模块接到1.5V的板载按键I/O。

根据实际连接器选线：公排针对公排针使用母对母，公排针对插孔使用公对母；J13是否已装排针应看实物。检查模块是否已有SCL/SDA/IRQ的3.3V上拉；缺失时补上合适的3.3V上拉。FPGA的I²C实现采用拉低/释放方式，不能把SDA当推挽输出争用。

## 首板分步验收

1. **机械和电气检查**：核对290 × 105 mm尺寸、25个独立触摸区、3组排针及六孔；确认阻焊完整、连接处无连锡、电极短线连接可靠。
2. **只接一块模块**：确认3.3V供电与共地，验证I²C应答、初始化和原始触摸状态。MPR121驱动已接入 `full/ContestFull.gprj`；需要核对新约束并下载完整工程，原板载按键程序不会自动识别触摸键。第1块模块的ELE0～7接J1，ELE8～11接滑条J4。
3. **扩展到三块**：逐键检查25个音名与上表一致，未使用通道不产生事件；按下及松开都能识别，邻键不误触。
4. **合奏检查**：验证两键、四键同时按下，并跨J1/J2/J3测试；松开一键时不能清掉仍按着的其他键，静置及松手后不能留下黏键。
5. **校准与音频联调**：在最终外壳/保护膜条件下调阈值、滤波及采样参数，再接现有FPGA→DAC→功放→喇叭链路测试。
6. **测量完整延迟**：测触摸变化到DAC模拟声音输出的完整链路。MPR121的采样间隔、IRQ到软件命令的时间和数字仿真结果不能单独当作≤10 ms已实现；普通万用表也不能验证毫秒级响应。

逐键阈值分析可用 [校准工具](calibration_guide_zh.md)：先在最终装配下采集功放断电/上电静音/演奏音量三个环境的真实数据，再运行离线分析。无数据、故障帧或噪声重叠时工具不给相应键的阈值候选；候选回写后还需独立复测。驱动的8/8/9通道数、状态mask、采样节奏、ready/valid与故障组释放要求见 [B驱动交接](touch25_driver_handoff_zh.md)。

本面板只提供触摸开/关状态。不能据此声称已经检测压力或击键速度；第二种独立演奏维度应由另一合适输入器件提供。
