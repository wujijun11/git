# Touch25 R1：线束与底托装配优化

本指南只补充现有 R1 的装配方案，不改变 PCB、Gerber、琴键映射或安装孔。对应面板为 290 × 105 mm、25 键 C4–C6，建议板厚 1.6 mm。

布局图见 [harness_layout.svg](harness_layout.svg) 或 [harness_layout.png](harness_layout.png)。**图为装配示意，不是制造图。面板、接口针位和六个安装孔按 R1 坐标绘制；MPR121 矩形是未定尺寸的占位，不代表实物外形、安装孔或底托加工尺寸。示意连线不代表实测线长。** 图使用正面坐标透视，未镜像；实际背面装配时左右会反转。

## 三组可拆线束

面板侧采用 **1×8、1×8、1×9，间距 2.54 mm 的母壳**，分别连接 J1、J2、J3 的公排针。将公排针焊在面板背面，使正面触摸区保持平整；先焊端针、校正方向，再焊其余针。母壳、压接端子与排针需要属于可配合的规格，不仅核对间距，还要核对针截面、插入深度和壳体尺寸。

模块端先按实物的 ELE 标注逐针连接；可用独立 1P 母端，确认方向后再制作成组插头。**不能默认两端从左到右直通。** 某些模块的 ELE0–ELE11 物理方向与面板针号相反，必须以印字和断电导通核对为准。模块没有公排针时，先确认焊接排针方案。

建议将三组线束标为“J1→MPR1”“J2→MPR2”“J3→MPR3”，例如使用黄、紫、蓝三种标签。每组 pin1 另加明显标记，线束两端都贴同一编号。线色仅用于识别，不决定电气功能。

| 面板针号 | J1 → MPR121 #1 | J2 → MPR121 #2 | J3 → MPR121 #3 |
| ---: | --- | --- | --- |
| 1 | E00 / C4 / MIDI60 → ELE0 | E08 / G#4 / MIDI68 → ELE0 | E16 / E5 / MIDI76 → ELE0 |
| 2 | E01 / C#4 / MIDI61 → ELE1 | E09 / A4 / MIDI69 → ELE1 | E17 / F5 / MIDI77 → ELE1 |
| 3 | E02 / D4 / MIDI62 → ELE2 | E10 / A#4 / MIDI70 → ELE2 | E18 / F#5 / MIDI78 → ELE2 |
| 4 | E03 / D#4 / MIDI63 → ELE3 | E11 / B4 / MIDI71 → ELE3 | E19 / G5 / MIDI79 → ELE3 |
| 5 | E04 / E4 / MIDI64 → ELE4 | E12 / C5 / MIDI72 → ELE4 | E20 / G#5 / MIDI80 → ELE4 |
| 6 | E05 / F4 / MIDI65 → ELE5 | E13 / C#5 / MIDI73 → ELE5 | E21 / A5 / MIDI81 → ELE5 |
| 7 | E06 / F#4 / MIDI66 → ELE6 | E14 / D5 / MIDI74 → ELE6 | E22 / A#5 / MIDI82 → ELE6 |
| 8 | E07 / G4 / MIDI67 → ELE7 | E15 / D#5 / MIDI75 → ELE7 | E23 / B5 / MIDI83 → ELE7 |
| 9 | — | — | E24 / C6 / MIDI84 → ELE8 |

面对琴键正面时，每组 pin1 在左，且对应方形焊盘；背面左右反转。**这 25 根线全部是电极信号，只接模块 ELE 输入，不接 3.3V、5V、GND 或 FPGA GPIO。** 模块的电源、SCL/SDA/IRQ 另做线束。完整琴键+滑条方案中，#1的ELE8–ELE11接滑条J4；#2的ELE8–ELE11、#3的ELE9–ELE11保持未启用，不接其他琴键。

## 2.54 mm 适配限制

| 项目 | J1 | J2 | J3 |
| --- | ---: | ---: | ---: |
| 针数 | 8 | 8 | 9 |
| 间距 | 2.54 mm | 2.54 mm | 2.54 mm |
| 接口中心，正面坐标 mm | (55,95) | (136,95) | (226,95) |
| pin1 坐标 mm | (46.11,95) | (127.11,95) | (215.84,95) |
| 首末针中心跨度 | 17.78 mm | 17.78 mm | 20.32 mm |

R1 的连接孔为 1.0 mm、焊盘外径 1.8 mm。选购排针需考虑成品孔公差；本指南不批准任何未经尺寸核对的替代封装。

**2.50 mm 不能当作 2.54 mm 直接替代。** 8 针首末跨度累计差 0.28 mm，9 针差 0.32 mm；即使能勉强插入，也不能据此确认可靠配合。带锁连接器、IDC 排线头或其他双排结构也不能仅凭名称替换现有单排孔位。若确实换连接器，需要另建修订版并重新检查制造文件。

## 模块位置和底托

将三块模块放在对应接口下沿外的绝缘底托上，让 ELE 针排朝向 J1/J2/J3。从接口离开后，线束向下沿外走，避免跨过白键或黑键的有效电极投影；避开功放输出线、喇叭线及 DAC 时钟线。每根外部电极线以 **实际总长 ≤50 mm** 为目标，留出插拔所需余量，不以示意图的端点直线距离代替线长。

在底托处固定线束外皮或插头尾部，分散拉力，使线束拉动不直接作用于排针焊点。固定点应留出插头拔出的空间，不粘住可拆插头。模块不要悬吊在线束上，也不要在有效触摸区下方放金属支架或模块铜面；底托和模块摆放确定后再校准触摸。

面板针中心距下边为 10 mm。y82–105 只有 23 mm 的下沿带，里面还包括走线、接口、孔位和丝印，**不是可以直接放模块的完整空白区域**。因此图把模块示意为下沿外固定；不能推定三块实物均能塞入面板背面范围。

底托加工前必须测量：

- 每块模块的长、宽、板厚和安装孔中心距；没有安装孔时采用绝缘卡托，不在模块或 R1 面板上临时钻孔。
- ELE 针排与数字针排的实际位置、针距、方向和已焊排针高度。
- 母壳长度、宽度、插合高度、可插拔空间及线束弯曲后的实际长度。
- 从面板背面焊点、插头和模块最高器件到托板的间隙。支柱高度按这些实测最大尺寸加装配余量确定，本指南不虚构一个通用高度。

面板现有六个 3.2 mm 非金属化安装孔中心保持为：

| 上沿 | 下沿 |
| --- | --- |
| (5,5) mm | (5,100) mm |
| (145,5) mm | (170,100) mm |
| (285,5) mm | (285,100) mm |

用六套 M3 绝缘支柱/螺丝固定面板。下中孔是 x170，不是 x145；底托不能上下直接复制孔位。避免螺丝、托板和模块焊点接触走线。无需为此次装配优化改动 PCB。

## 可以完成的装配清单

1. 准备 1×8 公排针两条、1×9 公排针一条、对应 2.54 mm 母壳及匹配端子/短线；模块端按实际针排选择单孔或成组母端。
2. 制作 8/8/9 三组线束，两端逐针编号，pin1 单独标记；电极线与模块供电/数字线分开。
3. 先测模块和插头，再制作下沿外绝缘托架；设置三个模块固定位置和三个线束拉力固定点。
4. 所有板断电、模块未插入时，用万用表逐根检查端到端导通和相邻线无短路；模块端从 ELE0 开始逐针核对，不能只看线色。
5. 模块和线束安装后，确认25路映射、插头可拆、模块可更换、螺丝可操作、信号线不受夹挤。
6. 最终外壳/薄 PET 膜条件下完成阈值校准，再测试单键、多键、松手无黏键及触摸到声音的完整延迟。

该优化只完善装配和可维护性，不表示触摸驱动、实物触摸效果或端到端延迟已验收。现有 FPGA 仍需 MPR121 初始化、触摸读取和25键映射；三块模块的 3.3V/GND 与独立 SCL/SDA/IRQ 接线按原装配指南执行。
