# 本轮代码修改与验证（2026-10-23）

电脑端 1.0.3 与 C3 蓝牙固件已编译完成。修改针对命令积压后的停止、断开清理，
以及蓝牙通知和订阅变化同时发生时的稳定性。接线与 UART 引脚保持现有约定。

## 修改

- `desktop/web/controller.js`：将外层命令队列限制为 128 个等待请求。
  “全部停止”会取消尚未发送的旧操作，等待当前事务的 ACK/数据边界结束后发停止。
  断开时取消旧队列，按 FPGA 已确认的远程音符释放，避免继续执行旧演奏。
  有意取消的操作不再被界面误报为新的通信故障。
- `desktop/web/protocol.js`、`mobile/web/protocol.js`：先登记正在等待的请求，
  再调用序号回调，防止回调重入时出现两个并发写入或无法结束的 Promise。
- `firmware/libraries/BridgeBLE/src/BLECharacteristic.cpp/.h`：保护 NimBLE
  订阅列表的读写；通知使用私有快照。在调用 BLE 主机和用户回调前释放锁。
  保留上一轮已修复的同步接收回调，避免延迟回调读到后一条命令。

## 实机边界

本轮没有向 FPGA 或 C3 烧录，也未验证真实蓝牙射频连接、FPGA ACK 或喇叭声音。
主机中的受控抢占验证的是容器与锁的代码行为，不等同于 ESP32 调度或真实无线测试。
需烧录本轮 C3 固件后再完成实机连接验证。
